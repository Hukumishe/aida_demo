# Как применить миграции в Railway

## Проблема
Таблицы не созданы в базе данных, потому что миграции не были применены.

## Решение: Применить миграции вручную

### Способ 1: Через Railway CLI (Рекомендуется)

1. Установите Railway CLI (если еще не установлен):
   ```bash
   npm i -g @railway/cli
   ```

2. Войдите в Railway:
   ```bash
   railway login
   ```

3. Подключитесь к проекту:
   ```bash
   railway link
   ```

4. Примените миграции:
   ```bash
   railway run npx prisma migrate deploy
   ```

### Способ 2: Через Railway Dashboard (SQL Editor)

1. Откройте сервис **Postgres** в Railway
2. Перейдите на вкладку **Database** → **Data**
3. Нажмите кнопку **"Connect"** (или используйте SQL Editor)
4. Скопируйте содержимое файла `prisma/migrations/20240129000000_init/migration.sql`
5. Вставьте SQL в редактор и выполните

### Способ 3: Через Railway Variables (временный DATABASE_URL)

1. Откройте сервис **Postgres** → **Variables**
2. Скопируйте `DATABASE_URL`
3. Локально создайте `.env` файл:
   ```
   DATABASE_URL=<скопированное значение>
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```
5. Примените миграции:
   ```bash
   npx prisma migrate deploy
   ```

### Способ 4: Проверить, почему release команда не выполнилась

1. Откройте сервис **AIDA_project** в Railway
2. Перейдите на вкладку **Deployments**
3. Проверьте логи последнего деплоя
4. Найдите секцию **"Release"** - там должны быть логи выполнения `prisma migrate deploy`

Если команда `release` не выполняется, возможно нужно:
- Проверить, что Procfile правильно настроен
- Убедиться, что миграции закоммичены в репозиторий

## После применения миграций

После успешного применения миграций нужно создать тестовых пользователей:

1. Используйте seed скрипт (если есть доступ к Railway CLI):
   ```bash
   railway run npm run seed
   ```

2. Или создайте первого OWNER вручную через SQL или API

## Проверка

После применения миграций проверьте:
1. В Railway Postgres → Database → Data должны появиться таблицы
2. Попробуйте залогиниться через API - ошибка должна исчезнуть
