# Добавление возможности удаления рабочих дней из графика работы для Lovable

## Контекст
На странице "График работы" (Work Schedule) пользователь может добавлять и редактировать рабочие дни сотрудников. Теперь нужно добавить возможность **удаления** рабочих дней из графика.

## API Endpoint для удаления рабочего дня

### DELETE `/schedule/day/:id`

**URL:** `https://aidaproject-production.up.railway.app/schedule/day/:id`

**Метод:** `DELETE`

**Headers:**
```
Authorization: Bearer <accessToken>
```

**Path Parameters:**
- `id` (обязательно): UUID рабочего дня, который нужно удалить

**Пример запроса:**
```
DELETE https://aidaproject-production.up.railway.app/schedule/day/123e4567-e89b-12d3-a456-426614174000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Response (200 OK):**
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "studioId": "uuid",
  "staffUserId": "uuid",
  "date": "2026-02-08T00:00:00.000Z",
  "startTime": "09:00",
  "endTime": "18:00",
  "breakStart": "13:00",
  "breakEnd": "14:00",
  "isDayOff": false,
  "createdAt": "2026-01-01T00:00:00.000Z",
  "updatedAt": "2026-01-01T00:00:00.000Z"
}
```

**Ошибки:**

**404 Not Found** - Рабочий день не найден:
```json
{
  "statusCode": 404,
  "message": "Schedule day with ID {id} not found",
  "error": "Not Found"
}
```

**403 Forbidden** - Нет доступа:
```json
{
  "statusCode": 403,
  "message": "Access denied to this schedule",
  "error": "Forbidden"
}
```

## Требования к UI/UX

### 1. Кнопка удаления в ячейке графика

**Где добавить:**
- В каждой ячейке календарной сетки, где есть рабочий день (не пустая ячейка)
- Кнопка должна быть видна при наведении (hover) или всегда видна, если это удобнее

**Визуальное оформление:**
- Иконка корзины/мусорного ведра (trash icon)
- Цвет: красный или серый
- Размер: небольшой, не перегружающий интерфейс
- Позиция: справа вверху ячейки или в правом нижнем углу

**Пример расположения в ячейке:**
```
┌─────────────────────┐
│ 09:00 - 18:00      🗑️│  <- кнопка удаления
│                     │
└─────────────────────┘
```

### 2. Подтверждение удаления

**Обязательно:** Перед удалением показывать диалог подтверждения (confirmation dialog)

**Текст диалога:**
- Заголовок: "Удалить рабочий день?"
- Сообщение: "Вы уверены, что хотите удалить рабочий день для [Имя сотрудника] на [Дата]? Это действие нельзя отменить."
- Кнопки:
  - "Отмена" (Cancel) - закрывает диалог
  - "Удалить" (Delete) - подтверждает удаление (красная кнопка)

### 3. Обработка состояний

**После нажатия "Удалить":**
1. Показать индикатор загрузки (loading state)
2. Отправить DELETE запрос на API
3. При успехе (200):
   - Убрать рабочий день из UI (ячейка становится пустой или показывает "—")
   - Показать уведомление об успехе: "Рабочий день успешно удален"
   - Обновить данные графика (можно перезагрузить или удалить из локального состояния)
4. При ошибке:
   - Показать сообщение об ошибке
   - Если 404: "Рабочий день не найден"
   - Если 403: "У вас нет прав для удаления этого рабочего дня"
   - Если другая ошибка: "Не удалось удалить рабочий день. Попробуйте еще раз."

### 4. Оптимистичное обновление (опционально)

Можно сразу убрать рабочий день из UI после подтверждения, а если запрос не удался - вернуть его обратно и показать ошибку.

## Технические детали

### Как получить ID рабочего дня

ID рабочего дня (`id`) должен быть доступен в данных, которые вы получаете при загрузке расписания:

**GET** `/studios/:studioId/schedule?date=YYYY-MM-DD`

Каждый элемент массива содержит поле `id`:
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",  // <- этот ID нужен для удаления
  "staffUserId": "uuid",
  "date": "2026-02-08T00:00:00.000Z",
  "startTime": "09:00",
  "endTime": "18:00",
  ...
}
```

### Структура данных для отображения

При отображении графика, сохраняйте `id` каждого рабочего дня, чтобы можно было его удалить:

```javascript
// Пример структуры данных
const scheduleData = {
  "staff-user-id-1": {
    "2026-02-08": {
      id: "123e4567-e89b-12d3-a456-426614174000",  // <- нужен для удаления
      startTime: "09:00",
      endTime: "18:00",
      ...
    }
  }
}
```

### Пример функции удаления

```javascript
async function deleteScheduleDay(scheduleDayId) {
  try {
    // Показать диалог подтверждения
    const confirmed = await showConfirmDialog({
      title: "Удалить рабочий день?",
      message: "Вы уверены, что хотите удалить этот рабочий день?",
    });
    
    if (!confirmed) return;
    
    // Показать загрузку
    setLoading(true);
    
    // Отправить запрос
    const response = await fetch(
      `https://aidaproject-production.up.railway.app/schedule/day/${scheduleDayId}`,
      {
        method: 'DELETE',
        headers: {
          'Authorization': `Bearer ${accessToken}`,
        },
      }
    );
    
    if (!response.ok) {
      if (response.status === 404) {
        throw new Error('Рабочий день не найден');
      } else if (response.status === 403) {
        throw new Error('У вас нет прав для удаления');
      } else {
        throw new Error('Не удалось удалить рабочий день');
      }
    }
    
    // Успех
    showNotification('Рабочий день успешно удален', 'success');
    
    // Обновить UI (убрать из графика)
    removeScheduleDayFromUI(scheduleDayId);
    
  } catch (error) {
    showNotification(error.message, 'error');
  } finally {
    setLoading(false);
  }
}
```

## Интеграция с существующим функционалом

### Связь с редактированием

- Если пользователь кликает на ячейку с рабочим днем, можно показать меню:
  - "Редактировать" - открывает форму редактирования
  - "Удалить" - показывает диалог подтверждения и удаляет

### Связь с добавлением

- После удаления рабочего дня, ячейка должна стать пустой
- Пользователь может снова добавить рабочий день на эту дату через существующий функционал добавления

## Важные замечания

1. **Права доступа:**
   - OWNER может удалять рабочие дни в любой студии
   - MANAGER и MASTER могут удалять только в своей студии
   - Backend автоматически проверяет права, но лучше показывать кнопку удаления только если есть права

2. **Валидация:**
   - Не нужно проверять на frontend, есть ли записи на этот день - backend не блокирует удаление
   - Если есть записи на удаляемый день, они останутся, но проверка доступности при создании новых записей не найдет рабочий день

3. **Формат даты:**
   - Дата в ответе приходит в формате ISO: `2026-02-08T00:00:00.000Z`
   - Для отображения используйте локальный формат даты

4. **Обновление данных:**
   - После удаления рекомендуется обновить данные графика (перезагрузить или обновить локальное состояние)
   - Это гарантирует, что UI синхронизирован с сервером

## Пример полного flow

1. Пользователь видит рабочий день в ячейке: "09:00 - 18:00"
2. Пользователь наводит курсор на ячейку → появляется иконка корзины
3. Пользователь кликает на иконку корзины
4. Появляется диалог: "Удалить рабочий день? Вы уверены..."
5. Пользователь нажимает "Удалить"
6. Показывается индикатор загрузки
7. Отправляется DELETE запрос
8. При успехе:
   - Ячейка становится пустой (показывает "—" или пустая)
   - Появляется уведомление: "Рабочий день успешно удален"
9. График обновляется

## Дополнительные улучшения (опционально)

1. **Массовое удаление:** Позволить удалять несколько дней сразу (чекбоксы + кнопка "Удалить выбранные")

3. **Клавиатурное удаление:** Нажать Delete при выбранной ячейке

4. **Визуальная обратная связь:** При наведении на кнопку удаления, ячейка подсвечивается красным
