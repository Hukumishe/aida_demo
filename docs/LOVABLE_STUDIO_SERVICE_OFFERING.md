## Промпт

### Задача

Обнови экран **каталога услуг** (список услуг в контексте выбранного филиала `studioId`), чтобы различать два уровня:

1. **Каталог организации** — услуга есть в сети или выключена **для всей организации** (поле `**isActive`** в объекте услуги, как раньше через `PATCH` общего обновления услуги).
2. **Конкретный филиал** — услуга **оказывается в этом филиале или скрыта только здесь** (например, в одном салоне больше не делают шугаринг, в другом — делают).

Бэкенд уже поддерживает это; фронт должен показать понятный UX и вызвать правильные эндпоинты.

### API

Базовый URL из env, заголовок `**Authorization: Bearer <accessToken>`**.


| Действие                                                        | Запрос                                                                                                                      |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Список услуг с флагом по филиалу                                | `**GET /studios/:studioId/services**`                                                                                       |
| Обновить поля услуги (в т.ч. `**isActive` на всю организацию**) | `**PATCH /studios/:studioId/services/:id`** — тело как раньше (`name`, `defaultPrice`, `isActive`, …)                       |
| Включить/выключить услугу **только в текущем филиале**          | `**PATCH /studios/:studioId/services/:id/studio-offering`** — тело `**{ "offered": true }**` или `**{ "offered": false }**` |


Подставляй реальный `**studioId**` из выбранного филиала в приложении, не шаблоны.

### Поля в ответе `GET .../services`

У каждой услуги теперь есть:

- Все прежние поля (`id`, `name`, `defaultDurationMin`, `defaultPrice`, `isActive`, `category`, …).
- `**isOfferedInStudio**` (boolean) — `true`, если услугу можно использовать **в этом филиале**: активна в каталоге орг (`**isActive`**) и **не отключена только для этого филиала**.

**Смысл для UI:**

- `**isActive === false`** — услуга выключена на уровне сети; в любом филиале недоступна. Переключатель «в филиале» можно не показывать или показывать disabled с подсказкой «сначала включите в каталоге».
- `**isActive === true**` и нужно скрыть услугу только в **текущем** филиале — вызывай `**PATCH .../studio-offering`** с `**offered: false**`. Другие филиалы не меняются.
- Чтобы снова включить в этом филиале — `**offered: true**`.

Не путай: старый `**PATCH**` с `**isActive**` меняет **всю организацию**; `**studio-offering`** — только выбранный `**studioId**`.

### Рекомендуемый UX

- В таблице/списке услуг для выбранного филиала показывай:
  - статус **«В каталоге сети»** / `**isActive`**;
  - отдельно **«В этом филиале»** или переключатель, синхронизированный с `**isOfferedInStudio`** и с результатом `**PATCH studio-offering**` (после успеха обнови список или оптимистично обнови локальное состояние).
- Подписи для пользователя: коротко объясни, что отключение **только в этом салоне** не отключает услугу в других точках сети.

### Ошибки

- **403** — нет доступа к филиалу; не повторяй запрос с тем же контекстом.
- **404** на `studio-offering` — неверный `serviceId` или услуга не из организации этого филиала.
