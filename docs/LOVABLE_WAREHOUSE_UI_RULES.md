# Склад: правила интерфейса (приход и добавление)

Отдельный промпт для правок по складу. Основная документация — [LOVABLE_WAREHOUSE.md](./LOVABLE_WAREHOUSE.md).

---

## Что изменить в UI

1. **Приход — только на основном складе**
   - Кнопку **«Приход»** показывать **только** на экране **«Единый склад»** (центральный склад).
   - На экране **«Склад филиала»** кнопку **«Приход»** **не показывать**.
   - Для прихода на основном складе использовать: **POST /warehouse/central/receipt** с телом `{ "productId": "uuid", "quantity": 10 }`.
   - Старый вызов прихода на филиале (`POST /studios/:studioId/warehouse/receipt`) больше не использовать — бэкенд возвращает 403: «Приход возможен только на основном складе».

2. **«+ Добавить» — только на основном складе**
   - Кнопку **«+ Добавить»** (добавить товар) показывать **только** на экране **«Единый склад»**.
   - На экране **«Склад филиала»** кнопку **«+ Добавить»** **убрать** (не показывать).
   - Добавление товаров на основном складе: **POST /warehouse/central/products**.
   - Вызов добавления на филиале (`POST /studios/:studioId/warehouse/products`) бэкенд отклоняет (403: «Добавлять товары можно только на основном складе»).

---

## Краткий чеклист

- [ ] Единый склад: есть кнопки «Приход» и «+ Добавить»; приход → `POST /warehouse/central/receipt`.
- [ ] Склад филиала: нет кнопок «Приход» и «+ Добавить»; только «С центра», «Списание», редактирование и удаление товара.
