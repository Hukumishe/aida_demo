# Сегменты клиентов (карточки на дашборде) — промпт для Lovable

## Задача

На экране клиентов (или дашборде студии) отобразить четыре карточки с количеством клиентов по сегментам:

1. **Спящие** — не записывались более 3 месяцев  
2. **Пропавшие** — не записывались более 6 месяцев  
3. **Не посещали** — нет ни одной записи (клиент добавлен, но никогда не был на приёме)  
4. **Новые** — за последнюю неделю (созданы в последние 7 дней или имели активность в последнюю неделю)

Данные брать из API. Бэкенд отдаёт только счётчики.

---

## API

**GET** `/studios/:studioId/clients/segments`

**Заголовки:** `Authorization: Bearer <access_token>`

**Параметр:** `studioId` — ID текущей студии (филиала).

**Доступ:** те же права, что у списка клиентов студии (владелец, зам, менеджер, админ своей студии).

**Ответ 200:**

```json
{
  "new": 0,
  "neverVisited": 0,
  "sleeping": 0,
  "missing": 0
}
```

- **new** — Новые (за последнюю неделю)  
- **neverVisited** — Не посещали (нет записей)  
- **sleeping** — Спящие (не записывались более 3 месяцев, но менее 6)  
- **missing** — Пропавшие (не записывались более 6 месяцев)

Клиенты из чёрного списка в подсчёте не участвуют.

---

## UI

- Четыре карточки (блоки) с иконками и подписями:
  - **Спящие** — иконка луны, текст «не записывались более 3 месяцев», число — оранжевый цвет.
  - **Пропавшие** — иконка человека с крестиком, «не записывались более 6 месяцев», число — красный.
  - **Не посещали** — иконка человека с минусом, «нет записей данных клиентов», число — нейтральный/чёрный.
  - **Новые** — иконка звёздочки, «за последнюю неделю», число — зелёный.
- При загрузке экрана вызывать `GET /studios/:studioId/clients/segments` и подставлять значения в карточки.
- Обработать ошибки (403, 404, сеть) и пустой/нулевой ответ.
