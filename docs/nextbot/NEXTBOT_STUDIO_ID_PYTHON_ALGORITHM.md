# Пошаговый алгоритм: динамический `studio_id` + Python Script в Nextbot

Цель: при вызове функций вроде `get_services_and_prices` в `args["studio_id"]` всегда попадает **реальный** `id` филиала из API, выбранный по переписке (или по умолчанию — единственный филиал).

---

## Этап 0. Подготовка в Nextbot

1. Создай **переменную сценария** (диалога), тип **строка**, имя например **`studio_id`**. Начальное значение можно оставить пустым.
2. (Опционально) Создай константы **`base_url`** и **`api_key`** как переменные сценария с фиксированными значениями — или задай их как скрытые параметры функций (не из переписки).

---

## Этап 1. Первый контакт с филиалами — `get_company_context`

1. В сценарии вызови функцию **`get_company_context`** (Python или иной экшен), чтобы получить список студий из `GET /nextbot/context`.
2. Убедись, что ответ доходит до модели / следующего шага в виде списка объектов с полями **`id`**, **`name`**, **`address`** (как в вашем API).

---

## Этап 2. Выбор филиала (логика диалога)

Выполни **один** из вариантов (или комбинацию).

### Вариант A — один филиал в ответе

1. Возьми **единственный** элемент массива студий.
2. Запиши **`element.id`** в переменную сценария **`studio_id`** (действие «установить переменную» / «сохранить в контекст» — как называется в твоём Nextbot).

### Вариант B — несколько филиалов

1. Покажи клиенту названия (и при необходимости адреса) **только из JSON** ответа `get_company_context`, без выдуманных списков.
2. Дождись выбора:
   - **кнопки** с `payload` = заранее подставленный **`id`** нужной студии из того же JSON, или  
   - **текст клиента** — модель по промпту сопоставляет слова с одной записью из списка.
3. После однозначного выбора запиши выбранный **`id`** в переменную сценария **`studio_id`**.
4. Если выбор неоднозначен — задай уточняющий вопрос, **не** вызывай функции с `:studioId` в пути, пока `studio_id` не записан.

### Вариант C — филиал задан заранее (например, отдельный бот на студию)

1. Один раз при старте диалога (или в настройках бота) зафиксируй **`studio_id`** константой в переменной сценария.

---

## Этап 3. Привязка к Python-функциям

Для **каждой** функции, в скрипте которой есть `args.get("studio_id", "")` (услуги, акции, verify, слоты, запись, регистрация и т.д.):

1. В блоке **«Параметры функции»** добавь параметр с **точным именем** **`studio_id`** (как в коде).
2. Укажи **источник значения** = переменная сценария **`studio_id`** (в UI Nextbot это может называться «значение из переменной», подстановка `{{studio_id}}` и т.п.).
3. Аналогично настрой **`base_url`** и **`api_key`**, если они передаются через `args`.

Проверка: при тестовом вызове в журнале/отладке в `args` должен быть непустой **`studio_id`**, совпадающий с `id` из API.

---

## Этап 4. Системный промпт (кратко)

Добавь правила для модели:

1. Идентификатор филиала для записи и API — только **`id`** из последнего ответа **`get_company_context`**.
2. Не выдумывать `studio_id`; при сомнениях — уточнить у клиента или использовать кнопки с `id` из API.
3. Не вызывать **`check_availability`**, **`create_booking_request`** и т.п., пока в сценарии не зафиксирован выбранный филиал (переменная **`studio_id`** заполнена).

(Готовые формулировки: **`docs/NEXTBOT_STUDIO_SELECTION.md`**, **`docs/NEXTBOT_FUNCTION_CALLING_STUDIO.md`**.)

---

## Этап 5. Проверка end-to-end

1. Новый диалог → вызов **`get_company_context`** → выбор филиала → сценарий записывает **`studio_id`**.
2. Вызов **`get_services_and_prices`** → в логах backend URL вида  
   `/nextbot/studios/<реальный-uuid-или-stu_...>/services`, **без** `%7B%7B` и без буквального `{{studio_id}}`.
3. Смена филиала в том же диалоге (если предусмотрено): повтори этап 2, перезапиши **`studio_id`**, следующий вызов должен уйти с новым id.

---

## Сводка потока данных

```text
get_company_context → JSON[{ id, name, address }, ...]
        ↓
выбор филиала (клиент / кнопки / один филиал)
        ↓
переменная сценария studio_id := выбранный id
        ↓
параметр функции studio_id ← переменная сценария
        ↓
Python: args["studio_id"] → URL .../studios/{id}/...
```

Скрипты-образцы: **`nextbot/xmind_python/`**.
