# Сравнение самых дешёвых вариантов хостинга для AIDA Backend

## Твои требования
- **NestJS backend** (Node.js 20)
- **PostgreSQL база данных**
- **Dockerfile** уже готов
- **Небольшая нагрузка** (MVP → production ready)

---

## 🏆 ТОП-5 самых дешёвых вариантов (от дешёвого к дорогому)

### 1. **Hetzner VPS** (самый дешёвый) 💰

**Цена:**
- **VPS CPX11**: €4.15/месяц (~$4.50)
  - 2 vCPU, 4GB RAM, 40GB SSD
  - Достаточно для твоего проекта
- **VPS CPX21**: €8.31/месяц (~$9)
  - 3 vCPU, 8GB RAM, 80GB SSD
  - Если нужен запас

**Что нужно сделать:**
- Арендовать VPS
- Установить Docker на VPS
- Запустить PostgreSQL в Docker
- Запустить твой backend в Docker
- Настроить Nginx как reverse proxy
- Настроить SSL (Let's Encrypt бесплатно)

**Плюсы:**
- ✅ Самая низкая цена
- ✅ Полный контроль
- ✅ Хорошая производительность (AMD EPYC)
- ✅ Локация в Европе (близко к Казахстану)

**Минусы:**
- ❌ Нужно самому настраивать всё (Docker, PostgreSQL, Nginx, SSL, бэкапы)
- ❌ Нет автоматического масштабирования
- ❌ Нужно самому следить за безопасностью и обновлениями

**Итого в месяц:** ~$4.50-9 (только VPS, всё остальное бесплатно)

---

### 2. **Render** (самый простой для начала) 🚀

**Цена:**
- **Web Service (Free Tier)**: $0
  - 512MB RAM, sleep после 15 мин бездействия
  - Не подходит для production
- **Starter Plan**: $7/месяц
  - 512MB RAM, всегда работает
- **Standard Plan**: $25/месяц
  - 2GB RAM, лучше для production
- **PostgreSQL**: $7/месяц (256MB) или $20/месяц (1GB)

**Что нужно сделать:**
- Подключить GitHub репозиторий
- Выбрать "Web Service"
- Указать Dockerfile
- Добавить env переменные
- Создать PostgreSQL базу

**Плюсы:**
- ✅ Очень просто (как Railway)
- ✅ Автоматический деплой из GitHub
- ✅ Бесплатный SSL
- ✅ Автоматические бэкапы БД
- ✅ Хорошая документация

**Минусы:**
- ❌ Дороже чем VPS
- ❌ Меньше контроля

**Итого в месяц:** $14-45 (backend + БД)

---

### 3. **Fly.io** (хороший баланс) ✈️

**Цена:**
- **Shared CPU**: ~$2-5/месяц
  - 256MB-512MB RAM
  - Pay-as-you-go (платишь за использование)
- **PostgreSQL**: $1.94/месяц (256MB) или $15.50/месяц (1GB)

**Что нужно сделать:**
- Установить `flyctl` CLI
- `fly launch` (создаст `fly.toml`)
- `fly deploy`
- Создать PostgreSQL через `fly postgres create`

**Плюсы:**
- ✅ Очень дешёво для малых проектов
- ✅ Глобальная сеть (близко к пользователям)
- ✅ Автоматический SSL
- ✅ Docker-based (твой Dockerfile работает)

**Минусы:**
- ❌ Нужно работать через CLI
- ❌ Может быть сложнее чем Render/Railway

**Итого в месяц:** ~$4-20 (backend + БД)

---

### 4. **Railway** (твой текущий) 🚂

**Цена:**
- **Hobby Plan**: $5/месяц + usage
  - $5 базовый + $0.000463/GB RAM/час + $0.000231/GB storage/час
  - На практике: ~$10-20/месяц для небольшого проекта
- **PostgreSQL**: Включена в план

**Плюсы:**
- ✅ Уже настроено и работает
- ✅ Очень просто
- ✅ Автоматический деплой
- ✅ Бесплатный SSL

**Минусы:**
- ❌ Может быть дороже при росте
- ❌ Меньше контроля

**Итого в месяц:** ~$10-20 (backend + БД)

---

### 5. **DigitalOcean App Platform** 🌊

**Цена:**
- **Basic Plan**: $5/месяц
  - 512MB RAM, 1GB storage
- **Professional Plan**: $12/месяц
  - 1GB RAM, лучше для production
- **PostgreSQL**: $15/месяц (1GB) или $60/месяц (4GB)

**Что нужно сделать:**
- Подключить GitHub
- Выбрать Dockerfile
- Настроить env переменные
- Создать PostgreSQL

**Плюсы:**
- ✅ Надёжно
- ✅ Хорошая документация
- ✅ Автоматический SSL

**Минусы:**
- ❌ Дороже чем VPS
- ❌ Меньше контроля

**Итого в месяц:** $20-27 (backend + БД)

## 🎯 Мои рекомендации по сценариям

### Сценарий 1: "Хочу максимально дёшево и готов настраивать"
**→ Hetzner VPS (€4.15/месяц)**

**План действий:**
1. Арендовать VPS CPX11
2. Установить Docker и Docker Compose
3. Настроить PostgreSQL в Docker
4. Настроить Nginx + Let's Encrypt
5. Запустить backend в Docker
6. Настроить автоматические бэкапы

**Время настройки:** 4-6 часов (первый раз)

---

### Сценарий 2: "Хочу дёшево, но без лишней возни"
**→ Fly.io (~$4-10/месяц)**

**План действий:**
1. Установить `flyctl`
2. `fly launch` (автоматически создаст конфиг)
3. `fly postgres create` (создаст БД)
4. `fly deploy` (задеплоит)
5. Готово!

**Время настройки:** 30-60 минут

---

### Сценарий 3: "Хочу просто, как сейчас на Railway"
**→ Render ($14-25/месяц)**

**План действий:**
1. Зарегистрироваться на Render
2. Подключить GitHub
3. Создать Web Service (выбрать Dockerfile)
4. Создать PostgreSQL
5. Добавить env переменные
6. Готово!

**Время настройки:** 15-30 минут

---

### Сценарий 4: "Оставить как есть"
**→ Railway ($10-20/месяц)**

Если всё работает и цена устраивает — можно оставить. Railway хорош для MVP.

## 💡 Специальные варианты (бесплатные/почти бесплатные)

### Oracle Cloud Free Tier (бесплатно навсегда!)

**Что дают:**
- 2 VPS (ARM Ampere A1) с 4 vCPU и 24GB RAM каждый
- 200GB storage
- **Бесплатно навсегда** (не trial!)

**Ограничения:**
- Нужна кредитная карта (но не списывают)
- ARM архитектура (но Node.js работает)
- Может быть сложно зарегистрироваться (часто блокируют)

**Стоит ли?**
- Если получится зарегистрироваться — **ДА!** Это лучший бесплатный вариант.
- Но регистрация может быть проблемой.

---

### Google Cloud Run (pay-as-you-go)

**Цена:**
- Первые 2 миллиона запросов в месяц — бесплатно
- Потом: ~$0.40 за миллион запросов
- PostgreSQL: можно использовать Cloud SQL или внешний

**Плюсы:**
- ✅ Очень дёшево для малых проектов
- ✅ Автоматическое масштабирование до 0 (не платишь когда не используется)

**Минусы:**
- ❌ Cold start может быть медленным
- ❌ Нужно настраивать через gcloud CLI

**Итого:** Может быть бесплатно или ~$1-5/месяц для малых проектов

---

### AWS Free Tier (только первый год)

**Что дают:**
- EC2 t2.micro: 750 часов/месяц (бесплатно первый год)
- RDS PostgreSQL: db.t4g.micro (бесплатно первый год)
- Elastic Beanstalk: бесплатно (платишь только за ресурсы)

**После первого года:**
- EC2: ~$8-10/месяц
- RDS: ~$15-20/месяц
- **Итого:** ~$23-30/месяц

**Стоит ли?**
- Если нужен только на год — да
- Для долгосрочного проекта — дорого
