# Кнопка «Опоздал» в карточке записи (Lovable)

## Обзор

В карточке записи (модальное окно деталей записи) нужно добавить кнопку **«Опоздал»**. Логика:

- Кнопка **«Опоздал»** показывается **только если** прошло **15 и более минут** с момента начала записи (`startAt`) и при этом **не была нажата** кнопка «Пришёл» (т.е. статус записи остаётся `BOOKED`).
- При нажатии «Опоздал»:
  - предоплата списывается в доход (так же, как при «Не пришёл»);
  - **запись не удаляется** — остаётся в расписании со статусом `BOOKED`, но с заполненным полем `forfeitedPrepaymentAmount`.
- Если после «Опоздал» нажать «Не пришёл», предоплата **не списывается второй раз** — учёт один раз.

---

## API

### Отметить запись как «Опоздал»

**Метод и URL:** `POST /studios/:studioId/appointments/:id/mark-late`

**Описание:** Отмечает запись как опоздание: предоплата добавляется в доход студии, запись остаётся в системе (не удаляется). Доступно только для записей в статусе `BOOKED`, у которых начало было не менее 15 минут назад.

**Параметры:**

- `studioId` (path) — ID студии  
- `id` (path) — ID записи  

**Заголовки:** `Authorization: Bearer <access_token>`

**Успешный ответ (200):**

```json
{
  "success": true,
  "message": "Appointment marked as late; prepayment added to income, appointment kept"
}
```

**Ошибки:**

- `400` — Слишком рано (меньше 15 минут с начала), нет предоплаты или предоплата уже списана (уже нажимали «Опоздал»).
- `403` — Нет доступа к записи.
- `404` — Запись не найдена.

**Права доступа:** те же, что у кнопок «Пришёл» и «Не пришёл» (владелец, заместитель, менеджер, админ, мастер — для своих записей).

---

## Когда показывать кнопку «Опоздал»

Показывать кнопку **только** когда выполняются **все** условия:

1. Статус записи: **`BOOKED`** (не `ARRIVED`, не `DONE`, не `CANCELLED`).
2. Текущее время **≥** `startAt + 15 минут` (прошло не менее 15 минут с начала записи).
3. У записи есть предоплата или цена услуги (чтобы было что списывать). Можно не проверять на фронте — бэкенд вернёт 400, если нечего списывать.
4. Опционально: не показывать, если у записи уже есть `forfeitedPrepaymentAmount > 0` (уже нажали «Опоздал»), чтобы не давать нажимать дважды.

**Не показывать:**

- Если статус `ARRIVED` или `DONE` — кнопка «Пришёл» уже использована или запись завершена.
- Если до начала записи ещё больше 15 минут — кнопка не отображается.
- Если уже нажали «Опоздал» (`forfeitedPrepaymentAmount` задан) — можно скрыть кнопку или оставить (бэкенд вернёт 400 при повторном нажатии).

---

## Логика «Опоздал» и «Не пришёл»

- **Только «Опоздал»:** предоплата один раз в доход, запись остаётся.
- **Только «Не пришёл»:** предоплата один раз в доход (если поздно), запись удаляется.
- **Сначала «Опоздал», потом «Не пришёл»:** предоплата учтена один раз (при «Опоздал»), при «Не пришёл» запись просто удаляется, повторно предоплата не списывается.

На бэкенде это уже реализовано: при «Не пришёл» предоплата добавляется в доход только если у записи ещё нет `forfeitedPrepaymentAmount`.

## UI/UX рекомендации

1. **Расположение:** в том же модальном окне «Детали записи», рядом с кнопками «Пришёл» и «Не пришёл» (или в той же группе действий).
2. **Текст кнопки:** «Опоздал».
3. **Стиль:** нейтральный или предупреждающий (например, оранжевый/жёлтый), не такой «опасный», как «Не пришёл».
4. **После нажатия:** обновить данные записи в модалке (в объекте записи появится `forfeitedPrepaymentAmount`); кнопку «Опоздал» скрыть или сделать неактивной, чтобы не нажимать повторно.
5. **Расчёт «15 минут»:** на фронте считать от `startAt` записи в той же временной зоне, что и отображаемое расписание (как для «Пришёл» / «Не пришёл»).

## Пример проверки на фронте (когда показывать кнопку)

```ts
const startAt = new Date(appointment.startAt);
const now = new Date();
const fifteenMinutesMs = 15 * 60 * 1000;
const canShowMarkLate =
  appointment.status === 'BOOKED' &&
  now.getTime() >= startAt.getTime() + fifteenMinutesMs &&
  (appointment.forfeitedPrepaymentAmount == null || appointment.forfeitedPrepaymentAmount === 0);
```

Вызов API при нажатии:

```ts
await fetch(`/api/studios/${studioId}/appointments/${appointment.id}/mark-late`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${accessToken}` },
});
// затем обновить запись в состоянии (добавится forfeitedPrepaymentAmount)
```
