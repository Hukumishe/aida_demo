# Промпт для Lovable: смена телефона мастера

Скопируйте в чат:

---

В карточке / профиле **мастера** добавь редактирование **телефона** (логин для входа).

**Кто может менять:** `ADMIN`, `OWNER`, `DEPUTY_OWNER`, `DEVELOPER`, `SERVICE` (не MASTER, не MANAGER).

**API:** `PATCH {API}/staff/{userId}`  
Body (только изменённые поля):

```json
{ "phone": "+77001234567" }
```

**Важно для ADMIN:** в body **только** `phone` — иначе 403 «Администратор может изменить у мастера только номер телефона».

**UI:**
- Поле «Телефон» с маской +7 (не read-only) для перечисленных ролей.
- Кнопка «Сохранить» или сохранение вместе с блоком «Учётная запись».
- Ошибка 400 «Phone already exists» — показать пользователю.
- Не использовать `PATCH .../profile` для телефона — там поля профиля, без phone.

**Проверка роли на фронте:**

```ts
const canEditStaffPhone = ['ADMIN', 'OWNER', 'DEPUTY_OWNER', 'DEVELOPER', 'SERVICE'].includes(user.role);
```
