# Промпт для Lovable: настройка WhatsApp-кнопки на лендинге

Скопируйте блок **«Промпт»** ниже в чат Lovable.

---

## Промпт

### Задача

На экране админки **«Лендинг»** добавь блок **«WhatsApp менеджера»** с настройкой:

1. Номер телефона WhatsApp, на который будет писать клиент.
2. Приветственное сообщение (prefill text), которое автоматически подставляется в чат.

Также подключи эти настройки к публичному лендингу, где уже есть кнопка перехода в WhatsApp.

### API (уже реализован на backend)

#### 1) Получить текущие настройки (публично)

**GET** `/studios/:studioId/landing/whatsapp-settings`

Ответ:

```json
{
  "whatsappPhone": "+77011234567",
  "whatsappPrefillMessage": "Здравствуйте! Хочу записаться.",
  "whatsappUrl": "https://wa.me/77011234567?text=%D0%97%D0%B4..."
}
```

- `whatsappUrl` уже готовая ссылка для кнопки.
- Если номер не задан, `whatsappUrl = null`.

#### 2) Обновить настройки (админка, Bearer)

**PATCH** `/studios/:studioId/landing/whatsapp-settings`

Тело:

```json
{
  "whatsappPhone": "+77011234567",
  "whatsappPrefillMessage": "Здравствуйте! Хочу записаться на услугу"
}
```

Поля опциональны, можно отправлять по одному.

Очистка поля:
- передай `null` или пустую строку `""`.

### Что сделать в админке

Добавь новый блок настроек в разделе «Лендинг»:

- Поле ввода **«Номер WhatsApp менеджера»**
- Текстовое поле/textarea **«Приветственное сообщение»**
- Кнопка **«Сохранить»**
- Кнопка/ссылка **«Проверить ссылку»** (открывает `whatsappUrl` в новой вкладке, если он не `null`)

Поведение:

1. При открытии страницы загрузить `GET .../whatsapp-settings`.
2. Заполнить форму значениями из ответа.
3. По «Сохранить» отправлять `PATCH`.
4. После успешного сохранения обновлять локальное состояние и показывать success toast.
5. Если `whatsappUrl` отсутствует — показать мягкую подсказку «Укажите номер WhatsApp, чтобы кнопка работала на сайте».

### Что сделать на публичном лендинге

В месте, где у вас кнопка «Написать в WhatsApp»:

1. Получать `GET /studios/:studioId/landing/whatsapp-settings`.
2. Использовать `whatsappUrl` как `href` кнопки.
3. Если `whatsappUrl` = `null`, скрыть кнопку или сделать disabled-состояние (предпочтительно скрыть).

### UX/валидации

- Номер: обычный текстовый input (backend сам нормализует формат).
- Сообщение: textarea до ~1000 символов.
- Сохранение: disabled во время запроса.
- Ошибки API: показывать текст ошибки в toast.
- Сохрани существующий визуальный стиль страницы.

### Тест-кейсы

1. Сохранить только номер → кнопка на лендинге открывает чат без текста.
2. Сохранить номер + текст → в WhatsApp подставляется сообщение.
3. Очистить текст (`null` или `""`) → остаётся только номер.
4. Очистить номер → `whatsappUrl = null`, кнопка на лендинге скрывается.
