# Промпт для Lovable: штраф мастера за опоздание (ADMIN)

Скопируйте в чат:

---

Добавь **штраф мастера за опоздание** в CRM: настройка в «Параметры системы» + кнопка в карточке записи для **ADMIN**.

### 1. Параметры системы

В экране **«Параметры системы»** (`GET/PATCH /studios/:studioId/settings`):

- Новое поле **`masterLateFineAmount`** (число, ₸, ≥ 0).
- Подпись: **«Штраф мастера за опоздание»**.
- Подсказка: при нажатии «Оштрафовать мастера» клиент получает скидку на эту сумму при завершении визита. **0** — кнопка скрыта.
- **Редактирование поля** (input + сохранение): роли **`OWNER`**, **`DEPUTY_OWNER`**, **`DEVELOPER`**, **`SERVICE`**. На фронте: `settings.permissions.canEditMasterLateFineAmount === true` или те же роли. **ADMIN / MANAGER / MASTER** — только просмотр (если settings уже загружены), без сохранения.

### 2. Кнопка «Оштрафовать мастера»

**Кто:** только `role === 'ADMIN'`.

**Когда показывать:**

- Статус записи `BOOKED` или `ARRIVED`.
- Сейчас ≥ **startAt + 10 минут** (локальное время филиала / сравнение по ISO `startAt` на клиенте).
- `masterLateFineAmount` в настройках филиала **> 0** (из `GET .../settings`).
- У записи **`masterLateFineAmount` ещё null/0** (штраф не применён).

**API:**

`POST {API}/appointments/{appointmentId}/fine-master-for-late`

Headers: `Authorization: Bearer <token>`

Body: пустой.

Ответ **200** — обновлённая запись с полем **`masterLateFineAmount`** (сумма штрафа).

Ошибки:

- **403** — не ADMIN
- **400** — рано (< 10 мин), штраф уже применён, сумма в настройках 0, неверный статус

**UX:**

- Подтверждение: «Оштрафовать мастера? Клиент получит скидку {сумма} ₸ при расчёте.»
- После успеха обновить карточку записи и историю.

### 3. Расчёт оплаты клиента

При **завершении визита** (`POST /appointments/:id/done`) бэкенд **автоматически** вычитает `appointment.masterLateFineAmount` из суммы к оплате.

Пример: услуги 10 000 ₸, штраф 1 000 ₸ → клиент платит **9 000 ₸** (с учётом предоплаты и бонусов как раньше).

На экране расчёта покажи строку **«Скидка за опоздание мастера: −{masterLateFineAmount} ₸»**, если поле > 0.

### 4. История

В «Истории» запись: **«Штраф мастера за опоздание: … ₸ (скидка клиенту при расчёте)»** (`action: STAFF_LATE_FINE`).
