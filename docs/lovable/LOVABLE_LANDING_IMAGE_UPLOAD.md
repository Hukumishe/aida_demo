# Промпт для Lovable: картинка карточки лендинга с устройства

Скопируйте блок **«Промпт»** ниже в чат Lovable.

Бэкенд AIDA отдаёт публичный URL после загрузки; в карточке лендинга по-прежнему хранится строка **`imageUrl`**.

---

## Промпт

### Задача

В модалке **«Добавить услугу»** (и при редактировании карточки) на экране **Лендинг** замени поле ввода «URL картинки» на сценарий **«Загрузить с устройства»**:

1. Пользователь выбирает файл → фронт отправляет его на бэкенд.
2. В ответ приходит **`{ "url": "https://..." }`** — подставь это значение в **`imageUrl`** при вызове API создания/обновления карточки (как если бы пользователь вставил ссылку вручную).

Опционально: оставь возможность **вручную ввести URL** (две вкладки или переключатель «файл / ссылка»), если это уместно в UX.

### Выпадающий список «Услуга»

- **`GET /studios/:studioId/landing/services`** (публичный) — это **уже созданные карточки** на лендинге, а не справочник услуг. Для пустой сети массив будет пустым — **не используй** этот запрос для селекта.
- Для селекта используй один из вариантов:
  - **`GET /studios/:studioId/landing/service-catalog`** (рекомендуется, Bearer) — явно «каталог для карточки лендинга»;
  - или **`GET /studios/:studioId/services`** — тот же состав услуг с полем **`isOfferedInStudio`**.

В ответе — массив услуг; для подписи в option используй **`name`**, значение — **`id`**.

### Загрузка файла

| Параметр | Значение |
|----------|----------|
| Метод | **`POST`** |
| Путь | **`/upload/landing`** (относительно базового URL API) |
| Заголовки | **`Authorization: Bearer <accessToken>`**; для `fetch` с `FormData` **не** задавай `Content-Type` вручную — браузер подставит boundary |
| Тело | **`multipart/form-data`**, поле файла: **`file`** (один файл) |

Пример логики:

```ts
const formData = new FormData();
formData.append('file', file);

const res = await fetch(`${apiBase}/upload/landing`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${accessToken}` },
  body: formData,
});

if (!res.ok) throw new Error(await res.text());
const { url } = await res.json();
// далее: imageUrl = url в DTO карточки лендинга
```

### Ограничения (бэкенд)

- Только изображения: **jpeg, png, gif, webp** (по MIME).
- Максимум **5 MB** за файл.
- При ошибке покажи текст ответа или понятное сообщение («недопустимый формат», «файл слишком большой»).

### Создание карточки после загрузки

Используй существующий эндпоинт создания/обновления карточки услуги лендинга (`imageUrl` в теле — как в текущей интеграции). URL с `upload/landing` уже абсолютный и ведёт на раздачу статики **`/uploads/...`** на том же хосте, что и API (проверь **`BASE_URL`** на проде, чтобы ссылки открывались с клиентов).

### Стили

Сохрани визуальный стиль модалки: превью миниатюры после выбора файла, кнопка «Загрузить с устройства», индикатор загрузки, disabled на «Добавить» пока идёт upload.
