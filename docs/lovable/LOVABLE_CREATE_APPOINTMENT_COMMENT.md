# Модалка «Новая запись» — поле «Комментарий» (промпт для Lovable)

**Задача:** в форме **«Новая запись»** (`CreateAppointmentModal`) добавить возможность ввести **комментарий к записи** при создании.

**Бэкенд уже готов** — менять API не нужно.

Связанные документы: `LOVABLE_APPOINTMENT_LOG.md`, `LOVABLE_APPOINTMENT_DETAILS_COMMENT_PREPAYMENT.md` (комментарий в карточке «Детали записи»).

---

## Где в UI

Модалка **«Новая запись»**: мастер, клиент, промокод, основная услуга, дата, время, **предоплата (₸)**.

**Добавить поле сразу после «Предоплата (₸)»** и **перед** кнопками «Отмена» / «Создать»:

| Подпись | Тип поля |
|---------|----------|
| **Комментарий** | `textarea`, 2–3 строки, необязательное |

Placeholder: `Комментарий к записи (необязательно)`  
Подсказка мелким текстом (опционально): *«Виден в карточке „Детали записи“ и в CRM»*

Стиль — как у остальных полей модалки (тёмная тема, те же отступы и ширина).

---

## API при создании

**POST** `/studios/:studioId/appointments`

В существующее тело запроса добавить поле **`comment`**, если пользователь что-то ввёл:

```json
{
  "staffUserId": "...",
  "clientId": "...",
  "serviceId": "...",
  "startAt": "2026-05-24T14:30:00+06:00",
  "prepaymentAmount": 4000,
  "comment": "Клиент просит мастера Настю"
}
```

- `comment` — **опционально**; не передавать или не включать в JSON, если поле пустое (после `trim()`).
- Не путать с `notes` клиента и с `comment` **допродажи** (`AppointmentUpsell`) — это отдельное поле **записи**.

Пример кода отправки:

```javascript
const body = {
  staffUserId,
  clientId,
  serviceId, // или serviceIds
  startAt,
  ...(prepaymentAmount > 0 ? { prepaymentAmount } : {}),
  ...(comment?.trim() ? { comment: comment.trim() } : {}),
};
```

---

## Поведение

- Поле **не обязательное** — создание записи без комментария работает как сейчас.
- После успешного создания комментарий приходит в ответе и в `GET .../appointments` как `appointment.comment`.
- В **«Детали записи»** тот же комментарий должен отображаться (см. промпт `LOVABLE_APPOINTMENT_DETAILS_COMMENT_PREPAYMENT.md`); при создании можно сразу показать его в открытой карточке, если открываете детали после create.
