# Промпт для Lovable: отмена без сгорания предоплаты (ADMIN)

Скопируйте в чат:

---

В модалке/карточке **записи** добавь действие **«Отменить без сгорания предоплаты»** — только для **`role === 'ADMIN'`**.

### Когда показывать кнопку

- Запись **не** в статусах `DONE`, `CANCELLED`.
- До начала **меньше 4 часов** (поздняя отмена) **и** есть предоплата (`prepaymentAmount > 0` или сумма услуг) — иначе обычная отмена и так не сжигает предоплату.
- `forfeitedPrepaymentAmount` ещё **0** (если уже «Опоздал» / сгорело — кнопку скрыть).

### API

**`POST {API}/appointments/{appointmentId}/cancel-without-prepayment-forfeit`**

Headers: `Authorization: Bearer <token>`

Body: пустой `{}` или без body.

Ответ **200** — обновлённая запись со `status: CANCELLED`, **`forfeitedPrepaymentAmount` не устанавливается**.

Ошибки:
- **403** — не ADMIN
- **400** — уже отменена / завершена / предоплата уже сгорела

### UX

- Подтверждение: «Отменить запись без сгорания предоплаты?»
- После успеха закрыть модалку, обновить журнал.
- Обычная кнопка «Отменить» остаётся: **`PATCH /appointments/:id`** `{ "status": "CANCELLED" }` — при поздней отмене предоплата **сгорает** (forfeitedPrepaymentAmount).

### История

В «Истории» запись: **«Запись отменена без сгорания предоплаты»**.
