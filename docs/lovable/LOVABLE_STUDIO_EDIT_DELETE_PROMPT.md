# Промпт для Lovable: редактирование и удаление филиала

Скопируйте блок **«Промпт»** ниже в чат Lovable **целиком**.

Backend AIDA обновлён: PATCH названия/адреса филиала и DELETE (только DEVELOPER).

---

## Промпт

### Задача

На экране организации (список филиалов — как на скриншоте «DEMO studio» → «Филиалы») добавить:

1. **Редактирование** названия и адреса филиала — для **OWNER**, **DEPUTY_OWNER**, **DEVELOPER**.
2. **Удаление** филиала — **только DEVELOPER**, с подтверждением.

---

### API

| Действие | Метод | Кто | Тело |
|----------|-------|-----|------|
| Карточка филиала + флаги UI | `GET /studios/:studioId` | по правам доступа | `permissions.canEditProfile`, `permissions.canDelete` |
| Изменить название/адрес | `PATCH /studios/:studioId` | OWNER, DEPUTY, DEVELOPER | `{ "name"?: string, "address"?: string \| null }` |
| Удалить филиал | `DELETE /studios/:studioId` | **только DEVELOPER** | — |

**PATCH:** хотя бы одно поле. Пустой `address` или `null` — очистить адрес.

**DELETE:** если к филиалу привязаны сотрудники (`studioId` или membership) — **400** с текстом «Нельзя удалить филиал: к нему привязаны сотрудники…». Показать toast; не удалять.

---

### UI

**Карточка филиала в списке:**

- Если `permissions.canEditProfile` (или роль OWNER/DEPUTY/DEVELOPER) — иконка **карандаш** / «Изменить» → модалка:
  - **Название** (обязательно при сохранении)
  - **Адрес** (опционально)
  - Сохранить → `PATCH /studios/:studioId`
- Если `permissions.canDelete` или `role === 'DEVELOPER'` — иконка **корзина** / «Удалить»:
  - Диалог подтверждения: «Удалить филиал «…»? Действие необратимо.»
  - OK → `DELETE /studios/:studioId` → убрать из списка, toast «Филиал удалён»
  - 400 → показать текст ошибки с бэка

**DEVELOPER** на экране «Организации» — те же действия в списке филиалов выбранной организации.

**OWNER / DEPUTY** — редактирование в настройках сети или там, где уже показывается список `GET /studios`; **удаление не показывать**.

---

### Acceptance criteria

- [ ] OWNER/DEPUTY/DEVELOPER сохраняют новое имя и адрес через PATCH
- [ ] DEVELOPER удаляет тестовый филиал без сотрудников
- [ ] При 400 (есть сотрудники) — понятное сообщение, филиал остаётся в списке
- [ ] У OWNER/DEPUTY нет кнопки удаления
