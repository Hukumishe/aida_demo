# Короткий промпт для Lovable: все мастера в форме записи

Скопируйте в чат:

---

В окне **«Новая запись»** / **«Выбор специалиста»** список мастеров брать **только** из:

`GET {API}/landing/studios/{studioId}/bookable-masters`

(при выбранных услугах: `?serviceId=srv_1&serviceId=srv_2` для каждой услуги).

**Не использовать** `GET /studios/{studioId}/landing/masters` и **не** фильтровать по `isVisible` — это только витрина главной страницы.

Показывать **всех** активных мастеров/админов филиала + пункт «Любой мастер». Порядок из `order` в ответе, если есть.

Услуги в форме записи: `GET .../bookable-services` (с `?staffUserId=` после выбора мастера), не `landing/services`.
