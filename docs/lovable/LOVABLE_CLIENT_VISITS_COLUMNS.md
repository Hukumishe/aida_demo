# Колонки «Визиты» и «Последний визит» в таблице клиентов — промпт для Lovable

## Задача

В таблице клиентов уже есть колонки **«Визиты»** и **«Последний визит»**. Нужно выводить в них реальные данные из API, а не прочерки.

Данные приходят в том же ответе, что и список клиентов — отдельный запрос не нужен.

---

## API

**GET** `/studios/:studioId/clients`  
(и с поиском: `GET /studios/:studioId/clients?q=...`)

**Заголовки:** `Authorization: Bearer <access_token>`

В каждом элементе массива клиентов теперь есть два дополнительных поля:

| Поле           | Тип    | Описание |
|----------------|--------|----------|
| `totalVisits`  | number | Количество завершённых визитов (записи со статусом «Выполнено») |
| `lastVisitAt`  | string \| null | Дата и время последнего завершённого визита в формате ISO (например `2026-02-20T14:00:00.000Z`) или `null`, если визитов не было |

**Пример элемента:**

```json
{
  "id": "uuid",
  "firstName": "Иванесса",
  "lastName": "Иванова",
  "phone": "+77777777777",
  "notes": "Вредная, Высокий болевой порог",
  "bonuses": 0,
  "discount": 0,
  "balance": 0,
  "isBlacklisted": false,
  "createdAt": "...",
  "updatedAt": "...",
  "totalVisits": 3,
  "lastVisitAt": "2026-02-20T14:00:00.000Z"
}
```

Если визитов не было:

```json
{
  "totalVisits": 0,
  "lastVisitAt": null
}
```

---

## Отображение в UI

1. **Колонка «Визиты»**
   - Показывать значение `totalVisits`.
   - Если `0` — можно вывести «0» или «—» по вашему стилю.

2. **Колонка «Последний визит»**
   - Если `lastVisitAt` есть — отформатировать дату (и при необходимости время) в локаль пользователя, например: «20.02.2026» или «20.02.2026, 14:00».
   - Если `lastVisitAt === null` — показать «—» или «Нет визитов».

3. **Типы и проверки**
   - Учитывать, что в старых ответах полей могло не быть: использовать `client.totalVisits ?? 0` и `client.lastVisitAt ?? null`, чтобы не было ошибок.

## Чеклист

- [ ] В таблице клиентов в колонке «Визиты» выводить `totalVisits` из объекта клиента.
- [ ] В колонке «Последний визит» выводить отформатированную дату из `lastVisitAt` или «—» при `null`.
- [ ] Обработать отсутствие полей (`?? 0`, `?? null`) для совместимости.
- [ ] Не добавлять новые запросы — данные уже в ответе списка клиентов.
