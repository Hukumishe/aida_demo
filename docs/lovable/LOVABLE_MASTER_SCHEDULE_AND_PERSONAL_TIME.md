# Роль MASTER: график и личное время — промпт для Lovable

**Бэкенд реализован.** Ниже — как должен вести себя UI для мастера.

---

## 1. График работы — только просмотр своего

### Запрет редактирования

Для роли **MASTER** отключить в UI:

- клик по ячейкам календаря для изменения времени;
- кнопки «Сохранить график», генерация 5/2 и 6/1;
- PATCH/DELETE/POST на расписание.

При ошибочном вызове API: **403** — «Мастер не может изменять графики работы».

### Только свой график

**GET** `/studios/:studioId/schedule?date=YYYY-MM-DD`  
Для MASTER в ответе только строки с `staffUserId === текущий userId`.

**GET** `/studios/:studioId/staff`  
Для MASTER в списке только **один** сотрудник — сам мастер (чтобы в сетке была одна колонка).

Не подгружать других мастеров для колонок календаря.

## 2. Личное время (busy slot)

Мастер блокирует слоты **только для себя** через busy slots.

### Создание

**POST** `/studios/:studioId/busy-slots`

```json
{
  "staffUserId": "<текущий userId мастера>",
  "startAt": "2026-05-24T14:00:00+06:00",
  "endAt": "2026-05-24T15:00:00+06:00",
  "comment": "Личные дела"
}
```

| Поле | UI | API |
|------|-----|-----|
| Причина брони | **Обязательное** textarea | `comment` |
| Мастер | не выбирать — подставить свой id | `staffUserId` |

Без `comment` → **400**: «Укажите причину брони…».

Можно бронировать **вне рабочих часов** (серое время), если указана причина.

### Просмотр

**GET** `/studios/:studioId/busy-slots?date=...` — только свои блоки.

### Редактирование / удаление

Только **свои** busy slots; чужие — 403.

---

## 3. UI: экран «Забронировать личное время»

Кнопка на странице графика или журнала (только MASTER):

- Дата и время начала / окончания (`+06:00`);
- **Причина брони** * (обязательно);
- «Забронировать» → POST busy-slots.

В сетке журнала/графика личные блоки — **серый фон** (`uiColorHint: "gray"` в API), подпись `displayLabel` или `comment`.

Рекомендуемый запрос журнала на день: `GET /studios/:studioId/appointment-log?date=YYYY-MM-DD` → поле `personalTimeSlots`.

## 4. Чеклист

- [ ] MASTER не редактирует чужие и свой график через UI.
- [ ] В календаре графика одна колонка — сам мастер.
- [ ] Форма личного времени с обязательной «Причиной брони».
- [ ] `staffUserId` = текущий пользователь при создании busy slot.
- [ ] Ошибки 403/400 показываются пользователю.
