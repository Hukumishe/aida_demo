# Собственные автосообщения (помимо сценарных) — промпт для Lovable

**Задача:** в разделе «Автосообщения Nextbot» дать возможность создавать **свои** шаблоны с расписанием, в дополнение к фиксированным сценариям (подтверждение, напоминание, холд, follow-up, оценка).

**Бэкенд готов.** API не менять.

Справка: `LOVABLE_NEXTBOT_AUTO_MESSAGES.md`, исправление сценарных форм — `LOVABLE_NEXTBOT_AUTO_MESSAGES_FORM_FIX.md`.

---

## Два режима в UI

При **«Новый шаблон»** — первый выбор:

| Режим | Описание |
|-------|----------|
| **Готовый сценарий** | Как сейчас: подтверждение, напоминание, холд, follow-up, оценка (см. FORM_FIX) |
| **Своё сообщение** | Форма ниже |

---

## Форма «Своё сообщение»

Загрузить схему:  
**GET** `/studios/:studioId/nextbot-auto-messages/custom-schedule-schema`

Ответ содержит `phases` (до/после), `offsetUnits`, подсказки.

### 1. Когда отправлять

Segmented control или radio:

- **До процедуры** → `phaseId: BEFORE_PROCEDURE`
- **После процедуры** → `phaseId: AFTER_PROCEDURE`

Из выбранной фазы взять `anchor` и `direction` (не показывать пользователю как enum).

| Выбор UI | anchor | direction |
|----------|--------|-----------|
| До процедуры | `APPOINTMENT_START` | `BEFORE` |
| После процедуры | `VISIT_DONE_AT` | `AFTER` |

### 2. Категория услуг *

**Обязательно.**  
`GET /services/categories?studioId=...` — только `isOfferedInStudio === true`.

Поле API: `serviceCategoryId`.

### 3. Тайминг

Одна строка: **число** + **единица** (select).

| Выбор «до» | Подпись |
|------------|---------|
| До процедуры | «За сколько **до** начала визита» |
| После процедуры | «Через сколько **после** завершения визита» |

Единицы: **Минут** / **Часов** / **Дней** → `offsetUnit`: `MINUTES` | `HOURS` | `DAYS`.

Число → `offsetValue` (минимум 1).

**Опционально** (только для «До процедуры»):  
«Мин. дней с брони до визита» → `minLeadDays` (целое ≥ 1 или не передавать).

### 4. Текст сообщения

Textarea + кнопки переменных из `GET .../variables` (`{{name}}`, `{{service}}`, …).

### 5. Активен

Switch `isActive` + подсказка про очередь PENDING.

## Сохранение (POST / PATCH)

**POST** `/studios/:studioId/nextbot-auto-messages`

```json
{
  "triggerType": "CUSTOM_SCHEDULED",
  "anchor": "APPOINTMENT_START",
  "direction": "BEFORE",
  "serviceCategoryId": "cat_xxxxxxxx",
  "offsetValue": 2,
  "offsetUnit": "HOURS",
  "minLeadDays": null,
  "messageText": "{{name}}, ждём вас {{appointmentDate}} в {{appointmentTime}}!",
  "isActive": true
}
```

Пример «после процедуры»:

```json
{
  "triggerType": "CUSTOM_SCHEDULED",
  "anchor": "VISIT_DONE_AT",
  "direction": "AFTER",
  "serviceCategoryId": "cat_xxxxxxxx",
  "offsetValue": 7,
  "offsetUnit": "DAYS",
  "messageText": "{{name}}, записывайтесь снова на {{category}}!"
}
```

## Логика (для подсказок в UI)

| Режим | Когда планируется | Когда уходит |
|-------|-------------------|--------------|
| До процедуры | Запись **забронирована**, визит в будущем | За N мин/ч/дн до `startAt` |
| После процедуры | Запись **завершена** | Через N мин/ч/дн после «Завершить» |

- Только записи, у которых услуга из **выбранной категории**.
- Нет `nextbotDialogId` / чёрный список → не отправится (журнал SKIPPED).
- **После процедуры:** если клиент снова **забронировал** услугу **той же категории** до отправки — сообщение **отменяется** (как follow-up).
- Перенос времени → пересчёт для «до процедуры».
- Отмена записи → отмена всех ожидающих сообщений по этой записи.

## Список шаблонов

В карточке показывать `triggerTypeLabel` из API (для custom: **«Своё сообщение»**) + категория + человекочитаемый тайминг:

- «За 2 ч до визита · Маникюр»
- «Через 7 дн. после визита · Депиляция»
