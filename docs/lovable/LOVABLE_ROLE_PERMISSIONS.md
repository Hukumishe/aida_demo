# Полномочия ролей (кратко, для WhatsApp)

*Можно скопировать блок ниже и вставить в WhatsApp.*

---

OWNER (Владелец)
• Все студии, всё можно: клиенты, записи, сотрудники, услуги, расписание, склады, дашборд, чёрный список
• Может создавать и удалять других владельцев и заместителей

DEPUTY_OWNER (Заместитель)
• То же что OWNER, но не может создавать/удалять владельцев и заместителей

ADMIN (Админ филиала)
• Только своя студия
• Клиенты, записи, сотрудники, услуги, расписание, склад филиала — всё по своей студии
• Не может: удалять клиентов и записи, центральный склад, дашборд, другие студии

MANAGER (Менеджер)
• Все студии, все записи и клиенты
• Может создавать и редактировать, отмечать прибытие/готово/не пришёл
• Не может: удалять клиентов и записи, центральный склад, дашборд

MASTER (Мастер)
• Только своя студия, только свои записи
• Видит записи без телефона клиента; может отмечать прибытие, готово, серое время (с комментарием)
• Не может: список клиентов, создание записей, удаление, склад, дашборд, управление сотрудниками

Удалять клиентов/записи — только OWNER и DEPUTY_OWNER.
Дашборд и центральный склад — только OWNER и DEPUTY_OWNER.
Телефон клиента скрыт только у MASTER.
