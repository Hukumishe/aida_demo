# Промпт для Lovable: смена телефона мастера

Скопируйте в чат:

---

В карточке **мастера / сотрудника** добавь поле **«Телефон для входа»** с возможностью редактирования.

### Права

Показывать редактирование **только** если `user.role` ∈ **`OWNER`**, **`DEPUTY_OWNER`**, **`DEVELOPER`**.

Или из **`GET /staff/:userId/profile`** → `permissions.canChangePhone === true`.

Мастер, админ, менеджер — **не** меняют телефон (только просмотр).

### API

**`PATCH {API}/staff/{userId}/phone`**

Headers: `Authorization: Bearer <token>`

Body:

```json
{ "phone": "+77001234567" }
```

Ответ 200 — обновлённый пользователь с полем `phone`.

Ошибки:
- **403** — нет прав
- **400** — номер занят / некорректный формат

Альтернатива: **`PATCH /staff/:userId`** с полем `phone` в body (те же права).

### UI

- Маска KZ (+7), перед отправкой нормализовать к `+7XXXXXXXXXX`.
- Кнопка «Сохранить» или сохранение вместе с формой сотрудника.
- После успеха обновить отображаемый `phone` в карточке.
- Подсказка: «Используется для входа в CRM».

### Не делать

- Не давать мастеру менять свой телефон через профиль (`PATCH .../profile` — без phone).
- Не показывать поле редактирования MANAGER / ADMIN / SERVICE.
