# Рабочие часы отдела маркетинга — промпт для Lovable (вкладка «Маркетинг»)

> ВАЖНО: это часы **отдела маркетинга** (менеджеров, которые выставляют счета Kaspi через Nextbot), а **не** часы работы самого салона и не расписание мастеров. Не путать с графиком студии или сменами персонала.

---

## Обзор

Во вкладке **«Маркетинг»** (там же, где уже настраивается акция «Приведи подругу» и лимит оплаты бонусами) нужно добавить блок **«Рабочие часы отдела маркетинга»**.

Эти часы используются Nextbot (ИИ-агентом) для маршрутизации оплаты после предварительной брони:

- **Внутри интервала [начало, конец)** — «день»: бэкенд ставит задачу живому маркетинг-менеджеру выставить счёт Kaspi.
- **Вне интервала** — «ночь»: клиенту сразу отдаются статичные реквизиты Kaspi (телефон + ФИО держателя), включается **30-минутный таймер удержания** предварительной брони. Если за 30 минут клиент не прислал чек и менеджер не подтвердил оплату — слот автоматически освобождается.

Если часы **не заданы** (оба null) — считается, что отдел маркетинга работает круглосуточно и ночной путь **отключён** (всегда идёт задача менеджеру).

Все поля хранятся на уровне **организации**, но читаются и пишутся через существующие эндпоинты студии (`GET /studios/:studioId/settings` и `PATCH /studios/:studioId/settings`).

---

## API

### GET /studios/:studioId/settings

В ответ (в существующий объект) добавляются 4 поля:

```json
{
  "loyaltyMode": "PRESET",
  "globalBonusPaymentLimitPercent": 30,
  "referFriendEnabled": true,
  "referFriendInviteeRewardType": "DISCOUNT_PERCENT",
  "referFriendInviteeValue": 20,
  "referFriendReferrerRewardType": "PERCENT_OF_PAYMENT",
  "referFriendReferrerValue": 10,

  "marketingHoursStartHour": 9,
  "marketingHoursEndHour": 22,
  "paymentKaspiPhone": "+77011234567",
  "paymentKaspiCardHolder": "Иванов И. И."
}
```

- `marketingHoursStartHour: number | null` — час начала смены отдела маркетинга, 0..23 (локальное время студии).
- `marketingHoursEndHour: number | null` — час окончания смены, 0..23. Допускается «переход через полночь» (например 22 → 6 означает «маркетинг на смене с 22:00 до 06:00 следующего дня»).
- `paymentKaspiPhone: string | null` — номер Kaspi, на который клиент переводит оплату в ночной режим.
- `paymentKaspiCardHolder: string | null` — ФИО держателя карты Kaspi (как показать клиенту).

### PATCH /studios/:studioId/settings

Роли: **OWNER / DEPUTY_OWNER / DEVELOPER / SERVICE** (как и остальные настройки вкладки). Тело — частичное, можно передать только нужные поля:

```json
{
  "marketingHoursStartHour": 9,
  "marketingHoursEndHour": 22,
  "paymentKaspiPhone": "+77011234567",
  "paymentKaspiCardHolder": "Иванов И. И."
}
```

Правила валидации (обрабатывает бэкенд, но дублируй на фронте, чтобы не ловить 400):

- `marketingHoursStartHour` и `marketingHoursEndHour` — целые числа **0..23** включительно.
- Пара «одно число + одно null» запрещена: либо оба числа, либо оба `null`.
- `marketingHoursStartHour !== marketingHoursEndHour` (иначе интервал пустой).
- Чтобы **очистить** рабочие часы маркетинга — отправь `{ "marketingHoursStartHour": null, "marketingHoursEndHour": null }`.
- Пустая строка в `paymentKaspiPhone` / `paymentKaspiCardHolder` трактуется бэкендом как очистка (становится `null`).

## UI во вкладке «Маркетинг»

Добавь блок **«Рабочие часы отдела маркетинга»** после существующих блоков «Лимит оплаты бонусами» и «Приведи подругу». Заголовок секции, короткое пояснение, затем форма.

### Короткое описание сверху блока

> Рабочие часы **отдела маркетинга** — когда менеджеры на смене и могут вручную выставлять клиентам счета Kaspi по заявкам от Nextbot.
> Не путать с графиком работы салона или сменами мастеров.
>
> В это время ИИ-агент передаёт оплату живому менеджеру. Вне этих часов клиент сразу получает статичные реквизиты Kaspi и 30 минут на оплату, после чего слот автоматически освобождается.

### Поля формы

1. **Переключатель** «Включить ночной режим оплаты» (boolean, только UI — на бэкенд это транслируется через значения часов):
   - Выключен → оба часа отправляются как `null`, поля ниже становятся неактивными. Маркетинг считается доступным 24/7.
   - Включён → показать поля ниже, обязательны оба часа.

2. **Начало смены отдела маркетинга** — селект часа (0..23). Подпись «Час начала», формат показа «09:00». По умолчанию 9.

3. **Конец смены отдела маркетинга** — селект часа (0..23). Подпись «Час окончания», формат показа «22:00». По умолчанию 22.
   - Подсказка: «Интервал задаётся по локальному времени студии. Поддерживается переход через полночь: например, 22 → 6 означает «смена с 22:00 до 06:00».»
   - Инлайн-ошибка если начало == конец.

4. **Телефон Kaspi** — текстовый инпут, маска под казахстанский номер (+7 ...), максимум 32 символа. Подпись «Номер, на который клиент переводит оплату».

5. **Получатель (ФИО)** — текстовый инпут, максимум 128 символов. Подпись «ФИО держателя карты Kaspi — показывается клиенту вместе с номером».

### Кнопки

- **«Сохранить»** — отправляет `PATCH /studios/:studioId/settings` с тем, что изменилось. После успеха — тост «Настройки сохранены».
- **«Отменить»** — сбрасывает форму до последнего значения с бэкенда.

### Подсказка под блоком (маленьким серым текстом)

> Если реквизиты Kaspi не заданы, а сейчас вне рабочих часов маркетинга — Nextbot всё равно задержит бронь на 30 минут, но клиенту попросит у менеджера реквизиты вручную. Рекомендуется заполнить оба поля.

---

## Права доступа

Блок редактируется тем же списком ролей, что и остальные настройки маркетинга:

- **DEVELOPER, OWNER, DEPUTY_OWNER, SERVICE** — могут видеть и менять.
- Прочие роли (ADMIN, MANAGER, MASTER, и т. д.) — не должны видеть блок совсем.

---

## Ответы бэкенда на ошибки

- **400 Bad Request**
  - «Задайте оба часа рабочего времени отдела маркетинга (marketingHoursStartHour и marketingHoursEndHour) или оба null».
  - «marketingHoursStartHour не может совпадать с marketingHoursEndHour».
  - Валидации `class-validator` (число, 0..23, длина строки).

- **403 Forbidden** — роль не из списка.
- **404 Not Found** — студия не найдена.

Покажи пользователю текст ошибки из `response.message` (если массив — первое значение).
