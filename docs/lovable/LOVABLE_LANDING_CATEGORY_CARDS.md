# Промпт для Lovable: карточки категорий услуг на лендинге

Скопируйте блок **«Промпт»** ниже в чат Lovable.

На лендинге нужны **карточки категорий** (название + описание, **без цены**). Бэкенд AIDA уже реализован.

---

## Промпт

### Задача

Добавь поддержку **категорий услуг на лендинге** в двух местах:

1. **Публичный лендинг** — блок с карточками категорий (только заголовок и текст).
2. **Админка CRM → экран «Лендинг»** — управление этими карточками (добавить / редактировать / удалить / порядок).

Карточки категорий **не заменяют** существующие карточки услуг (`GET .../landing/services`) — это **отдельный** блок.

### Публичный лендинг

**Запрос:** `GET /studios/:studioId/landing/categories` (без авторизации)

**Ответ** — массив, отсортированный по `order`:

```json
[
  {
    "id": "lcc_abc12defgh3",
    "categoryId": "sca_xyz98abc12",
    "title": "Уход за лицом",
    "description": "Процедуры для омоложения и увлажнения кожи",
    "order": 0
  }
]
```

- **`title`** и **`description`** уже **итоговые** для отображения (бэкенд подставил значения из CRM, если в карточке не переопределяли).
- **Цены нет** — не показывай цену и не запрашивай её.
- Картинки у категорий **нет** — только текст (можно оформить карточку в стиле сайта без фото или с декоративной иконкой).

Если массив пустой — блок не рендерить (или заглушка только в админке).

### Админка: список карточек категорий

На экране **Лендинг** добавь секцию **«Категории»** (рядом с существующими «Услуги» / «Мастера» / акциями):

- Загрузка списка: тот же **`GET /studios/:studioId/landing/categories`** (с Bearer — эндпоинт публичный, но с токеном тоже работает).
- Отображение: `title`, `description` (обрезка длинного текста в списке), кнопки **Редактировать** / **Удалить**.
- Drag-and-drop порядка → **`PATCH /studios/:studioId/landing/categories/reorder`**

Тело reorder:

```json
{
  "items": [
    { "id": "lcc_...", "order": 0 },
    { "id": "lcc_...", "order": 1 }
  ]
}
```

### Админка: модалка «Добавить категорию»

**Селект «Категория»** — не используй публичный `GET .../landing/categories` (это уже добавленные карточки).

Используй каталог для админки:

**`GET /studios/:studioId/landing/category-catalog`** (Bearer)

- Массив категорий из CRM с полями **`id`**, **`name`**, **`description`**, **`isOfferedInStudio`** (если есть).
- В option: подпись **`name`**, значение **`id`**.
- Показывай только категории с **`isOfferedInStudio !== false`** (если поле есть).
- **Исключи из селекта** категории, которые уже есть в текущем списке карточек лендинга (по `categoryId`), чтобы не ловить ошибку дубликата.

При выборе категории в форме **подставь в превью** (не обязательно отправлять, если пусто):

- заголовок ← `name`
- описание ← `description` из каталога

Поля формы (опциональные переопределения для лендинга):

| Поле | Обязательно | Примечание |
|------|-------------|------------|
| `categoryId` | да | из селекта |
| `title` | нет | если пусто — на сайте будет имя категории из CRM |
| `description` | нет | если пусто — описание из CRM |

**Создание:** `POST /studios/:studioId/landing/categories`

```json
{
  "categoryId": "sca_...",
  "title": "Необязательно",
  "description": "Необязательно"
}
```

Минимальный вариант — только `{ "categoryId": "sca_..." }`.

**Редактирование:** `PATCH /studios/:studioId/landing/categories/:id` — тело `{ "title"?, "description"? }` (категорию после создания не менять).

**Удаление:** `DELETE /studios/:studioId/landing/categories/:id`

Права: как у других настроек лендинга (OWNER, DEPUTY_OWNER, SERVICE, DEVELOPER).

### UX

- Сохрани визуальный стиль существующего экрана «Лендинг» и модалок карточек услуг.
- В модалке категории **не нужны**: загрузка картинки, поле цены, привязка к услуге.
- На публичном лендинге карточки категорий — отдельная сетка/секция; стиль согласуй с текущим лендингом (тёмная тема, типографика).
- Обработка ошибок API — toast с текстом ответа.

### Не путать

| Эндпоинт | Назначение |
|----------|------------|
| `GET .../landing/categories` | Карточки категорий **на лендинге** (публичная витрина + список в админке) |
| `GET .../landing/category-catalog` | Справочник категорий CRM для **селекта** при добавлении |
| `GET .../landing/services` | Карточки **услуг** (другая сущность, с картинкой и ценой услуги) |
| `GET /categories?studioId=...` | То же, что category-catalog, но общий CRM-эндпоинт; для лендинга предпочтителен **category-catalog** |

### Проверка

1. В CRM в категории услуг заданы `name` и `description`.
2. В админке «Лендинг» добавлена категория (можно без переопределения текста).
3. На публичном лендинге видна карточка с названием и описанием, **без цены**.
4. Редактирование текста только для лендинга не ломает данные в справочнике CRM.
5. Drag-and-drop меняет порядок на сайте.
