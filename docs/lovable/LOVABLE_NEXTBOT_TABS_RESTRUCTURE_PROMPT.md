# Nextbot / Маркетинг: вкладки «Шаблоны» и «Интеграции» — промпт для Lovable

Скопируйте блок **«Задача»** в чат Lovable. Бэкенд: поля webhook в `GET/PATCH settings` отдаются и сохраняются **только для роли `DEVELOPER`**.

---

## Контекст

Раздел **«Автосообщения Nextbot»** (или «Маркетинг → Nextbot») сейчас смешивает интеграцию, шаблоны и отдельные сценарии. Нужна чёткая структура вкладок.

Роли:
- **OWNER**, **DEPUTY_OWNER**, **DEVELOPER** — редактирование шаблонов, оценки, ДР (как сейчас на бэкенде).
- **DEVELOPER** — единственная роль с доступом к вкладке **«Интеграции»** и полям webhook.
- Остальные роли — раздел скрыть или только просмотр без edit.

JWT: `user.role` из профиля / токена.

---

## Задача

Перестроить навигацию раздела Nextbot на **три вкладки** (или подвкладки одного экрана):

```
[ Интеграции ]  [ Шаблоны ]  [ Журнал ]
     ↑ только DEVELOPER
```

### Вкладка 1 — «Интеграции» (только `role === 'DEVELOPER'`)

**Не показывать** пункт меню и вкладку OWNER / DEPUTY_OWNER / ADMIN / MASTER / MANAGER.

Содержимое (как сейчас блок «Подключение Nextbot»):

| Поле UI | API (`PATCH /studios/:studioId/settings`) |
|---------|-------------------------------------------|
| URL webhook исходящих сообщений | `nextbotOutboundWebhookUrl` |
| API-ключ (Bearer), опционально | `nextbotOutboundWebhookApiKey` |

- `GET /studios/:studioId/settings` — для DEVELOPER в ответе есть `nextbotOutboundWebhookUrl`, `nextbotOutboundWebhookApiKey`; для остальных ролей **этих полей нет** (не показывать пустые поля).
- Кнопка **«Сохранить»** — только PATCH перечисленных полей.
- Подсказка: webhook нужен для автосообщений и тестовой отправки; настраивает разработчик.

**Убрать из этой вкладки:** оценку визита, день рождения, список шаблонов, тестовую отправку.

---

### Вкладка 2 — «Шаблоны» (OWNER / DEPUTY_OWNER / DEVELOPER)

Всё, что относится к текстам и сценариям, **кроме** webhook.

#### 2.1. Список и CRUD автосообщений (как сейчас)

- `GET /studios/:studioId/nextbot-auto-messages`
- Создание / редактирование / удаление шаблонов (`POST`, `PATCH`, `DELETE`)
- Пресеты: `GET .../presets`, переменные: `GET .../variables`
- Custom-шаблоны по `LOVABLE_NEXTBOT_CUSTOM_AUTO_MESSAGES.md`

#### 2.2. Блок «Оценка после визита» (перенести сюда из интеграций)

Отдельная карточка **над или под** списком шаблонов:

| Поле UI | API |
|---------|-----|
| Заголовок задачи при оценке ≤ 3 (организация) | `feedbackLowRatingTaskTitle` |
| Ссылка 2GIS после оценки 4–5 (филиал) | `feedbackTwoGisUrl` |

Сохранение: `PATCH /studios/:studioId/settings` (только эти два поля в теле).

Подсказки как на текущем UI:
- задача назначается менеджеру организации;
- ссылка 2GIS уходит после высокой оценки в сценарии feedback.

Шаблон с `triggerType: FEEDBACK_REQUEST` остаётся в общем списке шаблонов; этот блок — **доп. настройки** сценария оценки.

#### 2.3. Блок «День рождения» (перенести сюда)

Отдельная карточка с иконкой торта, **не** в интеграциях.

Внутри карточки подвкладки: **Настройки** | **Журнал**

**Настройки:**
- `GET/PUT /studios/:studioId/nextbot-birthday/settings`
- Поля: `isActive`, `minClientLevel`, `daysBeforeBirthday`, `bonusType`, `bonusValue`, `discountValidDays`, `messageText`
- Детали: `LOVABLE_NEXTBOT_BIRTHDAY.md`

**Журнал:**
- `GET /studios/:studioId/nextbot-birthday/logs`

#### 2.4. Тестовая отправка

Карточка **внизу вкладки «Шаблоны»** (не на «Интеграциях»):

- `POST /studios/:studioId/nextbot-auto-messages/test-send`
- Если webhook не настроен (для owner поля нет в settings) — сообщение: «Обратитесь к разработчику для настройки интеграции Nextbot» вместо «укажите URL».
- DEVELOPER при пустом webhook — прежнее предупреждение «Сначала укажите URL на вкладке Интеграции».

---

### Вкладка 3 — «Журнал»

- `GET /studios/:studioId/nextbot-auto-messages/logs` — очередь автосообщений.
- Опционально второй подраздел или фильтр: журнал ДР (`GET .../nextbot-birthday/logs`) — либо оставить журнал ДР только внутри карточки «День рождения» на вкладке Шаблоны (как сейчас в макете).

---

## Поведение по ролям (сводка)

| Элемент | OWNER / DEPUTY | DEVELOPER | Остальные |
|---------|----------------|-----------|-----------|
| Вкладка «Интеграции» | скрыта | видна, edit | скрыта |
| Вкладка «Шаблоны» | видна, edit | видна, edit | скрыть / readonly |
| Оценка визита, ДР | на «Шаблонах» | на «Шаблонах» | — |
| Webhook в API GET | нет полей | есть | нет |
| PATCH webhook | 403 | OK | 403 |

---

## Чеклист приёмки

- [ ] DEVELOPER видит «Интеграции» только с webhook URL и API-key
- [ ] OWNER не видит вкладку «Интеграции» и не может сохранить webhook (403 при попытке)
- [ ] «Оценка после визита» и «День рождения» на вкладке «Шаблоны»
- [ ] Список шаблонов + тестовая отправка на «Шаблонах»
- [ ] Журнал на отдельной вкладке или согласованно с ДР
- [ ] Русский UI, стиль как у текущего маркетинга

---

## Справка API

| Что | Путь |
|-----|------|
| Settings (оценка + webhook*) | `GET/PATCH /studios/:studioId/settings` |
| Шаблоны | `/studios/:studioId/nextbot-auto-messages` |
| День рождения | `/studios/:studioId/nextbot-birthday/...` |
| Тест | `POST .../nextbot-auto-messages/test-send` |

\* webhook только DEVELOPER

Подробнее: `LOVABLE_NEXTBOT_AUTO_MESSAGES.md`, `LOVABLE_NEXTBOT_BIRTHDAY.md`.
