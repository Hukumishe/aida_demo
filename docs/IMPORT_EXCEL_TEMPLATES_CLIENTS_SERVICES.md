# Шаблон импорта из Excel: клиенты и услуги

Документ описывает формат таблиц для массовой загрузки данных в текущую схему AIDA.
Ориентир: текущие DTO и Prisma-модели (`Client`, `Service`, `ServiceCategory`).

## Как загружать корректно

- Рекомендуемый путь: импортировать через API, а не прямой SQL.
- Для клиентов использовать `POST /studios/:studioId/clients`.
- Для услуг использовать `POST /studios/:studioId/services`.
- Для категорий (до услуг) использовать `POST /studios/:studioId/service-categories`.
- Excel сохранять как CSV UTF-8 (разделитель запятая или `;` в зависимости от локали).

## Порядок импорта

1. Импортировать категории услуг.
2. Получить категории из API (`GET /studios/:studioId/service-categories`) и собрать маппинг `category_name -> category_id`.
3. Импортировать услуги, подставляя реальный `categoryId`.
4. Импортировать клиентов.

## Файл 1: `docs/templates/import_service_categories_template.csv`

Колонки:

- `name` (обязательно) - название категории, максимум 120 символов.
- `sortOrder` (опционально) - целое число >= 0.

Примечание:

- В рамках одной организации имя категории должно быть уникальным.

## Файл 2: `docs/templates/import_services_template.csv`

Колонки:

- `name` (обязательно) - название услуги.
- `defaultDurationMin` (обязательно) - длительность в минутах, целое число >= 1.
- `defaultPrice` (опционально) - цена в тг, целое число >= 0.
- `requiredStaffCount` (опционально) - сколько сотрудников нужно, целое число >= 1 (по умолчанию 1).
- `categoryName` (обязательно для удобства маппинга) - название категории из файла категорий.
- `categoryId` (обязательно при отправке в API) - id категории вида `sca_xxxxxxxxxx`.
- `audience` (опционально) - `WOMEN` или `MEN` (по умолчанию `WOMEN`).
- `isActive` (опционально, только если делаете прямой импорт в БД) - `true/false`, по умолчанию `true`.
- `bonusAccrualEnabled` (опционально, только для прямой БД) - `true/false`, по умолчанию `true`.

Важно:

- Через API создания услуги поля `isActive` и `bonusAccrualEnabled` в create не задаются, они выставятся по умолчанию `true`.
- `categoryId` должен существовать в этой же организации.

## Файл 3: `docs/templates/import_clients_template.csv`

Колонки:

- `firstName` (обязательно) - имя клиента.
- `lastName` (опционально) - фамилия.
- `phone` (обязательно) - телефон, уникален в рамках организации.
- `birthDate` (опционально) - дата рождения строго в формате `YYYY-MM-DD`.
- `notes` (опционально) - заметка.
- `bonuses` (опционально) - целое число >= 0.
- `discount` (опционально) - целое число 0..100.
- `balance` (опционально) - целое число >= 0.
- `referrerCode` (опционально) - реферальный код другого клиента.
- `referralCode` (опционально) - алиас для `referrerCode` (используйте одно из двух полей).
- `referralLinkId` (опционально) - id маркетинговой реферальной ссылки.

Важно:

- `phone` должен быть уникален в рамках одной организации, иначе ошибка.
- Если передан `referrerCode`/`referralCode`, код должен существовать у клиента в этой же организации.
- Если передан `referralLinkId`, ссылка должна быть активна и принадлежать этой же организации.

## Поля, которые НЕ нужно импортировать вручную

Они выставляются системой:

- Для клиентов: `id`, `organizationId`, `level`, `levelSetManually`, `totalPaidForLevel`, `isBlacklisted`, `blacklistReason`, `referralCode` (генерируется, если не задан), `createdAt`, `updatedAt`, и служебные реферальные поля.
- Для услуг: `id`, `organizationId`, `createdAt`, `updatedAt`.

## Минимальные примеры строк

Клиент:

- `firstName=Айжан, phone=+77071234567`

Услуга:

- `name=Женская стрижка, defaultDurationMin=60, categoryId=sca_abc12defgh3`

Категория:

- `name=Стрижки, sortOrder=0`
