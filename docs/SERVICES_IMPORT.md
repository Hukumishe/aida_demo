# Импорт услуг из CSV/XLSX (только DEVELOPER)

Функция для массовой загрузки каталога услуг в организацию. Доступна только роли **DEVELOPER** — на странице «Услуги салона» должна отображаться кнопка/меню «Импорт услуг» только у разработчиков.

## Эндпоинт

```
POST /services/import?organizationId=org_xxx[&dryRun=true]
Content-Type: multipart/form-data
Authorization: Bearer <JWT_DEVELOPER>

form field: file = <CSV | XLSX>
```

| Параметр | Обязательный | Описание |
|---|---|---|
| `organizationId` (query) | да | ID организации, куда импортировать |
| `dryRun` (query) | нет | `true` — проверить файл без записи в БД (превью результата) |
| `file` (form-data) | да | CSV или Excel, до 10 МБ |

Разрешены только `DEVELOPER`. `OWNER`, `MANAGER` и другие получат `403`.

## Формат файла

Первая строка — заголовки. Регистр и язык любые (поддерживаются русские и английские алиасы):

| Колонка | Алиасы | Обязательная | Формат |
|---|---|---|---|
| Категория | `категория`, `category`, `раздел`, `категория услуги` | да | текст |
| Услуга | `услуга`, `название`, `name`, `service`, `название услуги` | да | текст |
| Цена | `цена`, `price`, `стоимость`, `сумма` | да | число тенге (`3000`, `3 000`, `"3000тг"` — всё ок) |
| Длительность | `длительность`, `duration`, `время`, `минуты`, `время (мин)` | да | минуты (`30`) или текст (`1 час 30 мин`) |
| Аудитория | `аудитория`, `audience`, `пол`, `gender` | нет | `MEN` / `WOMEN` (по умолчанию `WOMEN`) |

### Пример CSV

```csv
Категория,Услуга,Цена,Длительность,Аудитория
Воск прайс,Подмышки воск,2000,10,WOMEN
Воск прайс,Спина полностью воск,5000,30,WOMEN
МУЖСКОЙ ПРАЙС ШУГАРИНГ,Подмышки муж,5000,15,MEN
Прайс шугаринг,Подмышки Топ,2000,10,WOMEN
Прайс шугаринг,Подмышки 1к,1500,10,WOMEN
Прайс шугаринг,Подмышки 2к,1000,10,WOMEN
```

## Поведение

- Категория, которой ещё нет — создаётся автоматически (`isActive: true`, `sortOrder: 0`).
- Услуга с тем же именем и аудиторией в организации — **пропускается**, импорт идемпотентный (можно безопасно повторять).
- Ошибочные строки (пустое имя, неверная цена/длительность и т.п.) попадают в `details[]` со статусом `error`, но не ломают импорт остальных.

## Ответ

```json
{
  "dryRun": false,
  "totalRows": 120,
  "createdCategories": [
    { "id": "sca_abc...", "name": "Воск прайс" }
  ],
  "skippedCategories": [
    { "id": "sca_xyz...", "name": "Skin's прайс" }
  ],
  "createdServices": 117,
  "skippedServices": 3,
  "errors": 0,
  "details": [
    { "row": 2, "status": "created", "category": "Воск прайс", "name": "Подмышки воск" },
    { "row": 5, "status": "skipped", "category": "Воск прайс", "name": "Усики воск", "reason": "Услуга уже существует (имя + аудитория)" },
    { "row": 7, "status": "error",   "category": "",            "name": "Лицо", "reason": "Не указана категория" }
  ]
}
```

## Коды ошибок

| Код | Когда |
|---|---|
| 400 | Файл пустой / не CSV-XLSX / не переданы заголовки / отсутствует organizationId |
| 403 | Роль не DEVELOPER |
| 404 | Указанной организации нет |

## Ожидания от фронтенда

1. На странице «Услуги салона» рядом с кнопкой «Добавить» показывать кнопку **«Импорт услуг»** — **только если `user.role === 'DEVELOPER'`**.
2. Кликом открывать модалку:
   - Инпут-файл (`accept=".csv,.xlsx,.xls"`).
   - Опционально чекбокс «Проверить без записи» → `dryRun=true`.
   - Ссылка «Скачать шаблон CSV» (статический файл с заголовками и парой строк).
3. После успешного ответа показать сводку: создано категорий X, услуг Y, пропущено Z, ошибок E; если `errors > 0` — раскрывающийся список с `details[]` (номер строки + причина).
4. Ошибки `400/403` показывать как toast с текстом из `message`.
5. После успешного импорта — перезапросить списки категорий и услуг для выбранной организации.
