# Реферальная программа «Приведи подругу» — промпт для Lovable

---

## Обзор

- У каждого клиента в профиле есть **уникальный реферальный код** (приходит в **GET /clients/:id** в поле `referralCode`).
- Друг может ввести этот код **в момент оплаты** (в модалке «Завершить запись») **только при самой первой записи** клиента в системе.
- Если у клиента уже есть другие записи (не первая запись), ввод реферального кода приведёт к ошибке: «Реферальный код можно использовать только при первой записи в системе».
- После фактического посещения (запись отмечена как выполненная):
  - **Пригласивший** получает бонусы: **10% от чека подруги** (сумма после вычета использованных бонусов).
  - **Новая клиентка** получает бонусы: **20% от чека** за первый визит.
- Бонусы начисляются только один раз за первого приведённого (первый визит с кодом).

---

## Промпт для Lovable (скопировать в чат)

Реализуй реферальную программу «Приведи подругу».

**1. В профиле клиента**

- Показать блок «Приведи подругу» (или в разделе бонусов/акций).
- Отображать **реферальный код** клиента: значение из `client.referralCode` (приходит в **GET /clients/:id**). Код уникален, например: `ABC123`.
- Отображать **сколько человек воспользовалось кодом**: поле `client.referredCount` (число) — приходит в **GET /clients/:id**. Например: «По твоему коду пришло 3 человека».
- Дать возможность **скопировать код** в буфер обмена (кнопка «Скопировать»).
- Краткий текст: друг может ввести код при оплате первого визита; подруга получит 20% от чека бонусами, ты — 10% от её чека.

**2. В модалке «Завершить запись» (первый визит клиента)**

- Добавить поле **«Реферальный код»** (необязательное): текстовый ввод. Если новая клиентка пришла по рекомендации, код вводится здесь.
- При нажатии «Завершить» отправлять **POST /appointments/:id/done** с телом, например: `{ "bonusesUsed": 0, "referralCode": "ABC123" }`.
- Код можно вводить в любом регистре; бэкенд обработает и начислит бонусы после завершения визита (10% пригласившему, 20% новой клиентке). Ошибки 400: «Реферальный код можно использовать только при первой записи в системе» (если у клиента уже есть записи); «Неверный реферальный код или нельзя использовать свой код» (если код неверный или свой).

**3. История бонусов**

- В истории бонусов (**GET /clients/:id/bonus-history**) появятся записи с типом начисления:
  - за приглашённую подругу (10% от чека) — тип можно отображать как «Реферал» / «Приведи подругу» (бэкенд шлёт `type: "REFERRAL_REFERRER"`);
  - за первый визит по коду (20%) — тип «Бонус за первый визит» (бэкенд шлёт `type: "REFERRAL_NEW_CLIENT"`).

## Промпт: только счётчик приведённых друзей (скопировать в чат Lovable)

```
В профиле клиента в блоке «Приведи подругу» добавь счётчик приведённых друзей.

Данные приходят из GET /clients/:id: в ответе есть поле referredCount (число) — сколько человек уже воспользовалось реферальным кодом этого клиента.

Нужно:
- Показать это число в блоке с реферальным кодом, например: «По твоему коду пришло N человек» (с учётом склонения: 1 человек, 2 человека, 5 человек).
- Если referredCount === 0, можно написать «Пока по твоему коду никто не пришёл» или «Приведи подругу — получи 10% от её чека».
- Данные уже есть в ответе API карточки клиента, дополнительных запросов не нужно.
```

## Таблица «Приведённые клиенты» на дэшборде

**API:** `GET /studios/:studioId/clients/referred`

**Ответ 200** — массив записей по приведённым клиентам:
```json
[
  {
    "clientId": "uuid",
    "clientFirstName": "Анна",
    "clientLastName": "Иванова",
    "clientPhone": "+77001234567",
    "referrerId": "uuid",
    "referrerFirstName": "Мария",
    "referrerLastName": "Петрова",
    "referrerCode": "ABC123"
  }
]
```

Колонки для таблицы: **Приведённый** (имя/фамилия клиента), **Телефон**, **Кто привёл** (имя/фамилия пригласившего), **Код пригласившего**. По клиенту можно сделать переход в карточку (clientId).

## Промпт для Lovable: дэшборд «Приведённые клиенты» в выпадающем списке

```
На дэшборде студии есть выпадающий список с вариантами (например «Динамика по дням», «Доход по услугам»). Добавь в этот выпадающий список новый пункт — отдельный дэшборд «Приведённые друзья» (или «Приведённые клиенты»).

Когда пользователь выбирает этот пункт:
- Показать отдельный вид дэшборда с таблицей приведённых клиентов (реферальная программа).
- Данные: GET /studios/:studioId/clients/referred (studioId — текущая студия). Ответ — массив: clientId, clientFirstName, clientLastName, clientPhone (приведённый), referrerId, referrerFirstName, referrerLastName, referrerCode (кто привёл).
- Таблица: колонки «Приведённый» (имя и фамилия), «Телефон», «Кто привёл» (имя и фамилия), «Код пригласившего». Кликабельная строка или «Открыть» — переход в карточку клиента (clientId).
- Если записей нет — текст «Пока нет приведённых клиентов».
- Доступ: как к остальным видам дэшборда студии (Owner, Deputy, Manager, Admin своего филиала).

Итого: в выпадающем списке дэшборда студии должен появиться третий (или дополнительный) вариант — «Приведённые друзья», по выбору которого отображается только эта таблица.
```

## API (кратко)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | /clients/:id | В ответе: `referralCode` — уникальный код; `referredCount` — сколько человек воспользовалось кодом этого клиента. |
| GET | /studios/:studioId/clients/referred | Список приведённых клиентов по студии (для таблицы на дэшборде). |
| POST | /appointments/:id/done | Тело может содержать `referralCode` (строка). При первом визите клиента с кодом: начисляются 10% пригласившему и 20% новой клиентке. |

## Чеклист для фронта

- [ ] В профиле клиента: блок с реферальным кодом (`client.referralCode`), число приведённых (`client.referredCount`) и кнопка «Скопировать».
- [ ] На дэшборде студии: в выпадающем списке (рядом с «Динамика по дням», «Доход по услугам») добавлен пункт «Приведённые друзья»; при выборе показывается отдельный вид с таблицей по GET /studios/:studioId/clients/referred (колонки: приведённый, телефон, кто привёл, код; переход в карточку клиента).
- [ ] В модалке «Завершить запись»: необязательное поле «Реферальный код»; при завершении передавать `referralCode` в теле POST /appointments/:id/done.
- [ ] В истории бонусов: отображать типы REFERRAL_REFERRER и REFERRAL_NEW_CLIENT (подписи на русском).
