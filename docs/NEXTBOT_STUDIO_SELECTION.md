# Как связать «филиал в диалоге» с `studioId` (WhatsApp + Nextbot)

**Пошагово: куда вставить абзац в промпт, URL и JSON-схему функций** → [`NEXTBOT_FUNCTION_CALLING_STUDIO.md`](./NEXTBOT_FUNCTION_CALLING_STUDIO.md).

В xmind нет отдельной функции «разрешить филиал» — после сужения `/nextbot` до функций промпта **`studioId` берётся только из ответа `get_company_context`** (`GET /nextbot/context`): у каждой студии в массиве есть **`id`**, **`name`**, **`address`**.

---

## 1. Промпт / сценарий

1. Вызови **`get_company_context`** и получи список студий.
2. Сопоставь слова клиента с **одной** записью (по `name` / `address`). При неоднозначности — уточнение или кнопки 1/2/3.
3. Сохрани **`selected_studio_id` = id`** из ответа API (не выдумывать).
4. Без **`selected_studio_id`** не вызывай **`check_availability`** и не создавай запись.
5. Список филиалов и адреса при записи — **только из JSON** `get_company_context`; статические блоки промпта с адресами **не использовать** для выбора филиала, если набор студий в API другой. **`id`** — только из API.

### Абзац для блока про запись / слоты

> **Сбор данных и поиск окон.** Выясни **филиал**, **услугу** и **дату**. После выбора филиала вызови **`get_company_context`**, сопоставь ответ клиента с одной студией из списка и сохрани её **`id`** как **`selected_studio_id`**. Пока **`selected_studio_id`** не зафиксирован, **`check_availability`** не вызывать. Когда есть филиал (с id), услуга и дата — вызови **`check_availability`** для этого **`selected_studio_id`**.

---

## 2. Nextbot (конструктор)

- Переменная **`studio_id`** из шага выбора филиала.
- URL: `.../nextbot/studios/{{studio_id}}/...`

### Инструменты (function calling) и `studioId`

В OpenAI/Nextbot у действия **`get_services_and_prices`** (и аналогичных с `:studioId` в пути) в **схеме аргументов** часто **нет** полей `studioId` / `selected_studio_id` — студия уже зашита в URL как `{{studio_id}}`. Тогда модель должна вызывать функцию **без лишних аргументов** (или только с теми параметрами, что реально объявлены в конструкторе). В системном промпте формулируй так: *«перед вызовом записать выбранный id в переменную сценария `studio_id`; вызов инструмента без передачи studio в JSON»* — иначе платформа выдаёт *unknown argument*.

См. [`NEXTBOT_XMIND_API.md`](./NEXTBOT_XMIND_API.md).

## 4. Замена блока «АДРЕСА ФИЛИАЛОВ И НАВИГАЦИЯ» в `aida_xmind.pdf`

В PDF после раздела про **`get_company_context`** часто идёт фиксированный список из 3 филиалов (Алатау, Евразия, LOTOS). Он **расходится** с реальным ответом API (другие `name` / `id`). Нужно **удалить** весь старый блок **«АДРЕСА ФИЛИАЛОВ И НАВИГАЦИЯ»** (включая пункты 1–3 с адресами, 2GIS и видео) и подпункт **«КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО выдумывать… адреса… которых нет в этом списке»**, если он относится только к этому статическому списку — иначе модель будет считать «истиной» три филиала из текста, а не JSON.

**Вставь вместо него этот текст** (можно в XMind / источнике и заново экспортировать PDF):

```text
ФИЛИАЛЫ И АДРЕСА (ИСТОЧНИК ДЛЯ ЗАПИСИ И studioId)
Перечень филиалов, их названия и адреса для выбора студии при записи и для подстановки studioId берутся строго из JSON-ответа функции get_company_context (поля id, name, address у каждого элемента списка студий).
Запрещено использовать для выбора филиала зафиксированные в других разделах промпта перечни адресов или названий, если они не совпадают с текущим списком из ответа get_company_context; приоритет всегда у данных API.
Этот раздел не использовать для выбора филиала, если в API другой набор студий — ориентируйся только на JSON последнего вызова get_company_context.
Если в ответе address равен null, называй клиенту филиал по name; не подставляй адреса из памяти или из устаревших статических блоков.
Ссылки на карты, навигацию и видео озвучивай только если они явно пришли в ответе портала или заведены в CRM для соответствующей студии; иначе ограничься полями из JSON.
```

Дополнительно в начале карточки **get_company_context** имеет смысл уточнить формулировку «опираться на эти данные… и адресах филиалов»: имелись в виду **данные из JSON-ответа**, а не статический список ниже (если статический список удалён).
