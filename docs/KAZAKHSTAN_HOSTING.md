## Зачем нужен хостинг в Казахстане?

1. **Низкая задержка (latency)** — быстрее для пользователей в Казахстане

## 🔧 Настройка на казахстанском хостинге

### Шаг 1: Аренда VPS

1. Выбери провайдера (Beget.kz, Hosting.kz и т.д.)
2. Выбери тариф (минимум 2GB RAM)
3. Выбери ОС: **Ubuntu 22.04 LTS** (рекомендуется)
4. Создай VPS

### Шаг 2: Подключение к серверу

```bash
ssh root@your-server-ip
```

### Шаг 3: Установка Docker

```bash
# Обновить систему
apt update && apt upgrade -y

# Установить Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# Установить Docker Compose
apt install docker-compose -y

# Проверить установку
docker --version
docker-compose --version
```

### Шаг 4: Настройка PostgreSQL в Docker

Создай файл `docker-compose.yml`:

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    container_name: aida-postgres
    environment:
      POSTGRES_USER: aida_admin
      POSTGRES_PASSWORD: your_strong_password
      POSTGRES_DB: aida_db
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./backups:/backups
    ports:
      - "127.0.0.1:5432:5432"  # Только локальный доступ
    restart: unless-stopped

volumes:
  postgres_data:
```

Запусти:
```bash
docker-compose up -d
```

### Шаг 5: Настройка Nginx + SSL

```bash
# Установить Nginx
apt install nginx certbot python3-certbot-nginx -y

# Настроить Nginx (создать конфиг)
nano /etc/nginx/sites-available/aida-backend
```

Конфиг Nginx:
```nginx
server {
    listen 80;
    server_name your-domain.kz;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Включи конфиг:
```bash
ln -s /etc/nginx/sites-available/aida-backend /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

Получи SSL:
```bash
certbot --nginx -d your-domain.kz
```

### Шаг 6: Деплой backend

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/AIDA.git
cd AIDA

# Создать .env файл
nano .env
```

`.env`:
```env
DATABASE_URL=postgresql://aida_admin:your_strong_password@localhost:5432/aida_db
JWT_SECRET=your_jwt_secret
JWT_REFRESH_SECRET=your_refresh_secret
JWT_EXPIRES_IN=15m
JWT_REFRESH_EXPIRES_IN=7d
PORT=3000
NODE_ENV=production
CORS_ORIGIN=https://your-frontend.kz
```

Запустить через Docker:
```bash
docker build -t aida-backend .
docker run -d \
  --name aida-backend \
  --env-file .env \
  -p 3000:3000 \
  --restart unless-stopped \
  aida-backend
```

Или через Docker Compose (добавить в `docker-compose.yml`):
```yaml
services:
  backend:
    build: .
    container_name: aida-backend
    env_file: .env
    ports:
      - "3000:3000"
    depends_on:
      - postgres
    restart: unless-stopped
```

## ❓ FAQ

**Q: Обязательно ли хранить данные в Казахстане?**  
A: Зависит от требований законодательства. Если нет специальных требований, можно использовать хостинг в России или Европе.

**Q: Какая задержка будет из Казахстана?**  
A: 
- Казахстан: ~5-20ms
- Россия: ~30-60ms
- Европа: ~80-150ms

**Q: Можно ли использовать Railway, если он работает?**  
A: Да, если нет требований по локализации данных. Railway работает хорошо, просто серверы не в Казахстане.

**Q: Нужен ли свой домен?**  
A: Не обязательно, но рекомендуется для production. Можно использовать поддомен провайдера.
