# Импорт клиентов из CSV/XLSX (только DEVELOPER)

Функция для массовой загрузки базы клиентов в организацию. Доступна только роли **DEVELOPER** — на странице «Клиенты» кнопка «Импорт клиентов» рендерится только для разработчиков.

## Эндпоинт

```
POST /clients/import?organizationId=org_xxx[&dryRun=true]
Content-Type: multipart/form-data
Authorization: Bearer <JWT_DEVELOPER>

form field: file = <CSV | XLSX>
```

| Параметр | Обязательный | Описание |
|---|---|---|
| `organizationId` (query) | да | ID организации, куда импортировать клиентов |
| `dryRun` (query) | нет | `true` — проверить файл без записи (для предпросмотра) |
| `file` (form-data) | да | CSV или Excel, до 10 МБ |

Разрешены только `DEVELOPER`. Остальные роли получат `403` — кнопки на UI у них тоже быть не должно.

## Формат файла

Первая строка — заголовки. Регистр и язык любые (поддерживаются русские и английские алиасы):

| Колонка | Алиасы | Обязательная | Формат |
|---|---|---|---|
| Имя | `имя`, `firstname`, `first name`, `name` | **да** | текст |
| Фамилия | `фамилия`, `lastname`, `last name` | нет | текст |
| Телефон | `телефон`, `phone`, `номер`, `номер телефона`, `mobile` | **да** | `+79991234567`, `8 (999) 123-45-67` — будет нормализовано |
| Пол | `пол`, `gender`, `sex` | нет | `MALE` / `FEMALE` (или `мужчина`/`женщина`, `м`/`ж`). Пусто/«не указано» = `null` |
| Дата рождения | `дата рождения`, `день рождения`, `др`, `birthdate`, `dob`, `birthday` | нет | `YYYY-MM-DD`, `DD.MM.YYYY`, `DD/MM/YYYY`, или дата из Excel-ячейки |
| Заметки | `заметки`, `заметка`, `комментарий`, `notes`, `comment` | нет | текст |
| Бонусы | `бонусы`, `баллы`, `bonuses` | нет | целое число ≥ 0 (по умолчанию 0) |
| Скидка | `скидка`, `discount` | нет | целое 0-100 (по умолчанию 0) |
| Баланс | `баланс`, `balance` | нет | целое ≥ 0 (по умолчанию 0) |
| Уровень | `уровень`, `level`, `статус` | нет | `BRONZE` / `SILVER` / `GOLD` / `DIAMOND` (или `бронза/серебро/золото/бриллиант`) |

### Пример CSV

```csv
Имя,Фамилия,Телефон,Пол,Дата рождения,Заметки,Бонусы,Скидка,Баланс,Уровень
Анна,Иванова,+77011234567,FEMALE,1992-05-15,Любит утро,500,5,0,SILVER
Марина,Петрова,8 (701) 555-77-88,женщина,1988-11-03,,0,0,0,BRONZE
Иван,Ким,+77021112233,мужчина,,Постоянный клиент,0,0,0,
Алина,,+77071112233,,,,0,0,0,
```

## Поведение

- **Телефон нормализуется**: из `8 (701) 555-77-88` получится `87015557788`. Дубликаты определяются по нормализованному телефону.
- Клиент с тем же телефоном в организации — **пропускается** (идемпотентно).
- Дубликат телефона внутри самого файла — тоже пропускается (остаётся первая встретившаяся строка).
- Если в строке передан `Уровень DIAMOND` — он сохраняется как ручной (`levelSetManually=true`), иначе уровень рассчитывается движком лояльности автоматически (PRESET-режим).
- Каждому клиенту выдаётся уникальный реферальный код (общая база рефералов).
- Ошибочные строки попадают в `details[]` со статусом `error` и не прерывают импорт остальных.

## Ответ

```json
{
  "dryRun": false,
  "totalRows": 3,
  "created": 2,
  "skipped": 1,
  "errors": 0,
  "details": [
    { "row": 2, "status": "created", "phone": "+77011234567", "name": "Анна Иванова" },
    { "row": 3, "status": "skipped", "phone": "87015557788",  "name": "Марина Петрова",
      "reason": "Клиент с таким телефоном уже есть в организации" },
    { "row": 4, "status": "created", "phone": "+77071112233", "name": "Алина" }
  ]
}
```

## Коды ошибок

| Код | Когда |
|---|---|
| 400 | Файл пустой / не CSV-XLSX / нет заголовков / отсутствует organizationId |
| 403 | Роль не DEVELOPER |
| 404 | Указанная организация не найдена |

## Ожидания от фронтенда

Один-в-один повторяет флоу «Импорт услуг» (`/docs/SERVICES_IMPORT.md`), только:

1. Кнопка **«Импорт клиентов»** — на странице «Клиенты», рядом с «+ Добавить клиента». Видна **только** для `DEVELOPER`.
2. Модалка с dropzone + чекбокс «Проверить без записи» + ссылка «Скачать шаблон CSV».
3. Запрос на `POST /clients/import?organizationId=<current>[&dryRun=true]`.
4. Вывод сводки: создано / пропущено / ошибок + аккордеон с `details[]`.
5. После реального импорта — рефетч списка клиентов.
