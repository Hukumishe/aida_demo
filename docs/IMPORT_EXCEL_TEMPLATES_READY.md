# Шаблоны импорта в формате Excel (листы + описание полей)

Ниже шаблоны представлены как листы Excel (таблицы), а не CSV-строки.
Вы можете создать один `.xlsx` с 3 листами: `Категории`, `Услуги`, `Клиенты`.

## Лист 1: Категории

### Таблица (пример данных)


| name        | sortOrder |
| ----------- | --------- |
| Стрижки     | 0         |
| Окрашивание | 1         |
| Маникюр     | 2         |


### Что означает каждое поле


| Поле      | Тип         | Обязательно | Описание                         | Пример  | Правила                                                            |
| --------- | ----------- | ----------- | -------------------------------- | ------- | ------------------------------------------------------------------ |
| name      | Текст       | Да          | Название категории услуги        | Стрижки | До 120 символов; в рамках одной организации должно быть уникальным |
| sortOrder | Целое число | Нет         | Порядок в списке (меньше = выше) | 0       | `>= 0`                                                             |


---

## Лист 2: Услуги

### Таблица (пример данных)


| name               | defaultDurationMin | defaultPrice | requiredStaffCount | categoryName | categoryId      | audience | isActive | bonusAccrualEnabled |
| ------------------ | ------------------ | ------------ | ------------------ | ------------ | --------------- | -------- | -------- | ------------------- |
| Женская стрижка    | 60                 | 12000        | 1                  | Стрижки      | sca_abc12defgh3 | WOMEN    | TRUE     | TRUE                |
| Мужская стрижка    | 45                 | 9000         | 1                  | Стрижки      | sca_abc12defgh3 | MEN      | TRUE     | TRUE                |
| Окрашивание корней | 120                | 18000        | 1                  | Окрашивание  | sca_qwe34rtyu78 | WOMEN    | TRUE     | TRUE                |


### Что означает каждое поле


| Поле                | Тип         | Обязательно       | Описание                                 | Пример          | Правила                                                 |
| ------------------- | ----------- | ----------------- | ---------------------------------------- | --------------- | ------------------------------------------------------- |
| name                | Текст       | Да                | Название услуги                          | Женская стрижка | Не пустое                                               |
| defaultDurationMin  | Целое число | Да                | Стандартная длительность в минутах       | 60              | `>= 1`                                                  |
| defaultPrice        | Целое число | Нет               | Цена услуги в тенге                      | 12000           | `>= 0`                                                  |
| requiredStaffCount  | Целое число | Нет               | Сколько сотрудников нужно для услуги     | 1               | `>= 1`, по умолчанию `1`                                |
| categoryName        | Текст       | Да (для человека) | Название категории для удобства проверки | Стрижки         | Служебная колонка для маппинга                          |
| categoryId          | Текст (ID)  | Да                | ID категории в системе                   | sca_abc12defgh3 | Должен существовать и принадлежать той же организации   |
| audience            | Enum        | Нет               | Целевая аудитория услуги                 | WOMEN           | Только `WOMEN` или `MEN`, по умолчанию `WOMEN`          |
| isActive            | Логический  | Нет               | Активна ли услуга в каталоге сети        | TRUE            | Для API create обычно не передается (по умолчанию TRUE) |
| bonusAccrualEnabled | Логический  | Нет               | Начислять ли бонусы за услугу            | TRUE            | Для API create обычно не передается (по умолчанию TRUE) |


---

## Лист 3: Клиенты

### Таблица (пример данных)


| firstName | lastName | phone        | birthDate  | notes                 | bonuses | discount | balance | referrerCode | referralCode | referralLinkId  |
| --------- | -------- | ------------ | ---------- | --------------------- | ------- | -------- | ------- | ------------ | ------------ | --------------- |
| Айжан     | Серикова | +77071234567 | 1994-03-21 | Любит утренние записи | 500     | 5        | 0       |              |              | srl_abc12defgh3 |
| Нурлан    | Ибраев   | +77015554433 | 1989-11-02 |                       | 0       | 0        | 0       | AB12CD       |              |                 |
| Дина      |          | +77775550011 |            |                       | 0       | 0        | 0       |              |              |                 |


### Что означает каждое поле


| Поле           | Тип          | Обязательно | Описание                           | Пример                | Правила                                                           |
| -------------- | ------------ | ----------- | ---------------------------------- | --------------------- | ----------------------------------------------------------------- |
| firstName      | Текст        | Да          | Имя клиента                        | Айжан                 | Не пустое                                                         |
| lastName       | Текст        | Нет         | Фамилия клиента                    | Серикова              | Можно пусто                                                       |
| phone          | Текст        | Да          | Телефон клиента                    | +77071234567          | Уникален в рамках организации                                     |
| birthDate      | Дата (текст) | Нет         | Дата рождения                      | 1994-03-21            | Строго `YYYY-MM-DD`                                               |
| notes          | Текст        | Нет         | Комментарий о клиенте              | Любит утренние записи | Любой текст                                                       |
| bonuses        | Целое число  | Нет         | Бонусный баланс                    | 500                   | `>= 0`                                                            |
| discount       | Целое число  | Нет         | Скидка в процентах                 | 5                     | От `0` до `100`                                                   |
| balance        | Целое число  | Нет         | Баланс в тенге (историческое поле) | 0                     | `>= 0`                                                            |
| referrerCode   | Текст        | Нет         | Реф.код другого клиента            | AB12CD                | Используйте либо это поле, либо `referralCode`                    |
| referralCode   | Текст        | Нет         | Алиас `referrerCode`               | AB12CD                | Используйте одно из двух: `referrerCode`/`referralCode`           |
| referralLinkId | Текст (ID)   | Нет         | Маркетинговая ссылка-источник      | srl_abc12defgh3       | Ссылка должна существовать, быть активной и из той же организации |


---

## Поля, которые не нужно загружать вручную

- Клиенты: `id`, `organizationId`, `level`, `createdAt`, `updatedAt` и другие системные поля.
- Услуги: `id`, `organizationId`, `createdAt`, `updatedAt`.
